# Clear 审计平台

当前正式版本为 **v0.10.0 多模态手动工具 CPU 版**。打开[手动工具目录](http://127.0.0.1:8879/apps)，已有页面可按 `Ctrl+F5` 刷新。

详细文档：[主界面与平台使用说明书](../../docs/Clear审计平台使用说明书.md) · [手动工具分册](../../docs/Clear手动工具使用说明.md) · [OCR 分册](../../docs/ClearOCR详细使用说明.md) · [架构设计与实现思路](../../docs/Clear架构设计与实现思路.md)。这些文档适用于当前固定入口，另行区分独立 OCR 研发线。

双击本目录 **启动智能审计.cmd**，使用固定入口启动。原工作区继续使用；无需把业务资料复制到发行程序目录。三个主导航沿用智能审计、审计项目、手动工具。本轮集中建设手动流程，Agent 默认关闭。

保留 ClearOCR、ClearClassification、ClearData、ClearForensics，新增人脸比对与音频分析。印章识别位于 OCR 扩展入口，CAT-Net 深度取证位于图像取证扩展入口。四类工作台支持导入资料、真实模型分析、原件对照、人工修订、保存重开、成果归集和导出；印章核准字段可转入 Data，归集成果可在审计项目调查事项中引用。

新增四类能力当前在 CPU 运行，GPU 选项保持关闭。原有 OCR/分类 GPU 能力保留。单文件上传上限 128 MiB，音频解析另有四小时上限；冷加载可能较慢。长录音、业务准确率和 A4000/A6000 目标机尚未验收，完整升级仍有待办。

独立离线介质已包含程序、前端、所选模型/字典/配置、Python 环境、DLL、编解码、字体、许可证、哈希清单、诊断、备份工具及离线安装材料。程序包使用空业务工作区，业务资料和业务分类模型通过独立备份迁移。详见[交付记录](../../docs/platform-automation/多模态手动工具升级交付记录-20261013.md)与[内网部署及验收说明](../../docs/platform-automation/多模态手动审计验收与内网部署说明.md)。

在 PowerShell 中查询状态或停止：

```powershell
& 'F:\OCR\release\Clear\product-entry.ps1' -Action status
& 'F:\OCR\release\Clear\product-entry.ps1' -Action stop
```

停止仅作用于核实过身份的本产品进程。先在工具中完成或取消活动任务，再停止平台。

`current.json` 登记当前程序、哈希、工作区和兼容要求。旧版及升级前冷备份保留；不要用旧日期目录的启动脚本打开已写入多模态记录的工作区。回退时先停服务，将升级前备份恢复到新的 F 盘目录并使用适配版本；保留升级后的原工作区。

源码、模型、工作区、日志、缓存、临时文件及交付包均保存在 F 盘。
