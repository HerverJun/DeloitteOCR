# Clear 审计平台

当前正式版本为 **v0.14.0 通用工作能力与审计工具版**。打开[平台首页](http://127.0.0.1:8879/)或[智能审计](http://127.0.0.1:8879/agent)，已有页面可按 `Ctrl+F5` 刷新。修复内容、真实验收和回退证据见[实施与验收记录](../../docs/platform-automation/Agent通用能力恢复实施与验收-20261019.md)。

普通问题直接在主输入框提出；文件任务可读取、搜索、编辑任务副本并运行PowerShell/Python脚本，实际成果可下载。图片/PDF识字、批量多列清洗、OCR选参及新底稿使用已有专业服务组合完成。开放聊天需配置模型；明确本地操作入口仍按实际能力可无需模型。任务可追加、暂停后继续，正式人工复核与署名仍由真实用户完成。

详细文档：[主界面与平台使用说明书](../../docs/Clear审计平台使用说明书.md) · [手动工具分册](../../docs/Clear手动工具使用说明.md) · [OCR 分册](../../docs/ClearOCR详细使用说明.md) · [架构设计与实现思路](../../docs/Clear架构设计与实现思路.md)。这些文档适用于当前固定入口，另行区分独立 OCR 研发线。

双击本目录 **启动智能审计.cmd**，使用固定入口启动。原工作区继续使用；无需把业务资料复制到发行程序目录。主导航为平台首页、智能审计、审计项目、手动工具。Agent 保持启用，登记中的 `agent_enabled: true` 由固定启动器沿用；现有模型连接和凭据继续使用，执行内核为 DeepSeek Harness。详情见[内核迁移与验收](../../docs/platform-automation/Clear-Agent-Harness迁移与验收-20261016.md)。

保留 ClearOCR、ClearClassification、ClearData、ClearForensics，新增人脸比对与音频分析。印章识别位于 OCR 扩展入口，CAT-Net 深度取证位于图像取证扩展入口。四类工作台支持导入资料、真实模型分析、原件对照、人工修订、保存重开、成果归集和导出；印章核准字段可转入 Data，归集成果可在审计项目调查事项中引用。

新增四类能力当前在 CPU 运行，GPU 选项保持关闭。原有 OCR/分类 GPU 能力保留。单文件上传上限 128 MiB，音频解析另有四小时上限；冷加载可能较慢。长录音、业务准确率和 A4000/A6000 目标机尚未验收，完整升级仍有待办。

当前006候选只读复用登记中 `shared_program` 指向的 `F:\OCR\release\Clear\versions\0.10.0\program`；单独候选目录不包含完整运行时和模型。完整迁移须同时保留该依赖闭包、登记及三组件业务备份。

原0.10.0独立离线介质已包含程序、前端、所选模型/字典/配置、Python 环境、DLL、编解码、字体、许可证、哈希清单、诊断、备份工具及离线安装材料。程序包使用空业务工作区，业务资料和业务分类模型通过独立备份迁移。详见[交付记录](../../docs/platform-automation/多模态手动工具升级交付记录-20261013.md)与[内网部署及验收说明](../../docs/platform-automation/多模态手动审计验收与内网部署说明.md)。

在 PowerShell 中查询状态或停止：

```powershell
& 'F:\OCR\release\Clear\product-entry.ps1' -Action status
& 'F:\OCR\release\Clear\product-entry.ps1' -Action stop
```

停止仅作用于核实过身份的本产品进程。先在工具中完成或取消活动任务，再停止平台。

`current.json` 登记当前程序、哈希、工作区和兼容要求。旧版、升级前三组件冷备和已启动验证的回退副本保留，具体路径见本次修复报告；不要用旧日期目录的启动脚本打开已写入多模态记录的工作区。回退时先停服务，将升级前备份恢复到新的 F 盘目录并使用适配版本；保留升级后的原工作区。

源码、模型、工作区、日志、缓存、临时文件及交付包均保存在 F 盘。
