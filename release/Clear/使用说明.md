# Clear 智能审计

双击本目录 **启动智能审计.cmd**，打开 <http://127.0.0.1:8879/>。启动会复用当前登记的模型和运行时，不复制模型。重复启动返回已有服务。

先在次级设置中填写支持工具调用的大模型地址、模型和凭据。输入审计目标、添加资料并发送，Agent 按需选择已注册工具和模型，展示真实执行过程与成果。资料授权属于当前任务，项目归集不会自动扩大范围。

三个主入口是智能审计、审计项目和手动工具。任务计划、背景、规则及技能调整放在可收起的详情中；连接高级参数和技能版本资源放在设置。自动保存目标草稿与历史会话继续可用。

需要手动修改时，使用“接管”进入工具目录，打开相关成果、保存，再明确选择成果版本带回原任务。四类工具的独立手动操作也可继续使用。取消带回会保留人工状态；人工暂停的原生任务须在原工具恢复。

审计项目中可以查看资料、发现与成果。日常底稿可直接下载；需要正式留档时，选择目标正式档案和程序，把明确的草稿版本转为正式草稿。原作者、证据和来源版本会保留，转档不会替代人工签名；源草稿后续更新不会覆盖正式快照。

在 PowerShell 中查询状态或停止：

```powershell
& 'F:\OCR\release\Clear\product-entry.ps1' -Action status
& 'F:\OCR\release\Clear\product-entry.ps1' -Action stop
```

停止只作用于经过路径、启动时间、工作区和端口核实的本产品进程。有活动 Agent 或原生任务时，先在平台及对应工具完成或停止。关机由用户自行决定，启动入口没有关机安排。

`current.json` 登记当前候选、哈希、共享资产、工作区、端口与数据兼容要求。保留其中引用的目录和历史候选。启动先检查哈希、实际迁移版本、必要数据库结构和证据记录格式；工作区的读取能力记录会阻止稳定入口直接降级。不要用旧日期目录的独立启动脚本打开当前工作区。恢复历史数据应先停服务，把备份恢复到新的 F 盘目录，再登记适配候选；关闭 Agent 可保留手动工具。

源码、工作区、日志、缓存和临时文件全部留在 F 盘。当前版本及检查证据见 [主开发索引](F:/OCR/docs/platform-automation/README.md)。
