# 产品需求与范围

## 产品定位

平台帮助使用者从少量已标注图片出发，建立一个项目专属的分类器，对大量图片批量分类，并通过有限人工复核持续改进。通用性来自可配置类别、数据集和模型适配器；不意味着同一个模型无需数据即可覆盖所有业务。

首版以单机运行的 Web 工作台为默认形态。浏览器负责管理与复核，后端负责图片访问、训练、推理和导出。初始用户是数据整理人员与模型维护人员，小团队可以由一人承担两种角色。

## 明确的边界

| 维度 | 首版范围 | 后续条件 |
| --- | --- | --- |
| 分类目标 | 单标签整图分类，项目之间独立配置 | 多标签需要独立标签规范、sigmoid 损失与逐标签阈值 |
| 类别 | 2 类起步，支持增加类别并生成新标签版本 | 层级分类在确有类别树需求时增加 |
| 图像 | JPEG PNG 静态 WebP BMP，统一 RGB | PDF TIFF 多页 GIF HEIC 另做导入适配器 |
| 输入 | 服务端已登记目录、类别子目录、CSV 清单、少量浏览器上传 | 对象存储和外部系统连接按场景增加 |
| 数据规模 | 每类几十张起步，批量任务以 15 万张验收 | 更大规模由压测决定是否更换存储与调度 |
| 训练 | 冻结预训练编码器与线性分类头 | 只在误差分析支持时增加局部微调 |
| 推理 | 单张试用、批量任务、恢复、CSV JSONL 结果 | TensorRT、多 GPU 调度按实测瓶颈决定 |
| 人工反馈 | 待复核池、限额抽样、改类、确认、创建新数据版本 | 不承诺人工复核少量后所有任务结果都正确 |
| 部署 | Windows 本机开发，可迁移 Linux GPU 内网服务 | SaaS 多租户、计费、SSO 不是首版范围 |

平台不把文档类别写死在业务代码中。文档示例使用发票、收款码截图、合同、其他；工业场景可以另建项目配置合格品、缺陷类型等。极小缺陷、小二维码、依赖细小文字的分类需单独验证，必要时进入检测、切块或 OCR 流程。

## 主要用户流程

1. 创建项目，定义互斥类别、正反例与排除规则，选择文档或自然图像预处理配置。
2. 登记数据目录或上传样本，生成清单，检查坏图、重复图、冲突标签和来源分组。
3. 冻结标签版本与数据集版本，锁定 train、val、test，查看每类样本与独立组数。
4. 创建训练任务，对比小范围候选，查看各类错误、混淆矩阵和不同阈值下的复核量。
5. 导出并校验模型包，选定默认模型版本。
6. 创建批量任务，固定图片快照与模型包版本，查看进度、错误、资源与预计剩余时间。
7. 导出结果；需要时另建归档复制任务。
8. 从待复核池和随机抽查池选择当轮预算内的图片，人工确认后生成下一版数据集。

已有任务始终绑定创建时的模型版本。切换项目默认模型只影响新任务。

## 页面与交互范围

| 页面 | 主要内容 | 关键动作 |
| --- | --- | --- |
| 项目列表与设置 | 项目、类别定义、默认模型、数据目录 | 新建、修改下一版标签、归档项目 |
| 数据集 | 缩略图、来源、类别数量、坏图与重复组 | 导入、标注、解决冲突、发布版本 |
| 实验与评估 | 配置、日志、每类指标、混淆矩阵、错误样本 | 训练、取消、比较、导出模型 |
| 模型库 | 模型版本、来源、预处理、验收状态 | 校验、设为默认、回退 |
| 批量任务 | 阶段进度、成功失败计数、速度、错误样本 | 暂停、恢复、重试失败、导出 |
| 人工复核 | 缩略图、预测、真实标签、分组、快捷键 | 修改、确认、跳过、提交下一版数据 |
| 运行状态 | GPU、磁盘、队列、进程心跳、依赖版本 | 下载诊断报告 |

界面默认展示任务阶段与计数；模型实现细节集中在实验配置和诊断页面。数据列表分页或虚拟滚动，缩略图惰性加载，不能一次载入 15 万张。复核快捷键支持类别编号、下一张、跳过；保存后返回明确状态，避免刷新丢失标注。

## 分类结果的语义

- `accepted`：当前模型预测达到该类别的接受阈值；仍然是模型结果。
- `needs_review`：已成功推理，但未达到接受条件。
- `failed`：读取、解码、推理或身份校验失败，不能伪装成“其他”。
- 人工标注单独保存 `human_confirmed` 与标签修订记录，不覆盖原始预测。

“其他”是有训练样本的普通业务类别。“待复核”是结果状态。两者不能合并。置信分数默认是 softmax 分数，未校准时不在 UI 中解释为正确概率。

## 非功能要求

任务与模型可追溯；异常退出后可恢复；坏图不阻断整批；批处理内存有界；原图默认只读；数据目录与模型目录可迁移；日志避免写入敏感图片内容。所有页面和导出均支持中文类别及带空格的 Unicode 文件路径。

本机模式默认只监听 127.0.0.1。启用内网共享时补齐登录、权限、目录访问限制与反向代理 TLS；这与允许远程浏览器提交服务器任意路径是不同能力。

## 首版产品验收

必须完成从项目建立、样本导入、训练、导出、批量推理、复核到再训练的闭环。重启不能丢失已提交结果，失败图片必须逐条可解释；旧数据集和旧模型必须可重现。精度、复核预算和整批时长按业务指标验收，尚无已确认数值，不能用演示数据或公开基准替代。
