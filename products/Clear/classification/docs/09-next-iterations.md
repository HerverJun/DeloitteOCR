# 下一轮开发与验收

v0.2 已完成 Flowers102 公共数据评测、MobileNetV4/RepViT 接入、正则化分类头、输入预取与有界缓存、独立 CPU 推理验证；见 [实测报告](11-public-benchmark-and-v02.md)。以下工作仍需继续，公共花卉数据不能替代用户业务验收。

| 优先级 | 工作 | 完成标准 |
| --- | --- | --- |
| P0 | 接入真实业务样本 | 明确类别、来源分组、误报/漏报成本、人工复核预算；独立测试集封存 |
| P0 | 比较编码器与阈值 | 在同一划分比较 ResNet18 / DINOv2 224 / 336，报告各类精确率、召回率及拒识覆盖率；指标达到业务目标 |
| P1 | 实际大批量性能与恢复 | 使用目标分辨率及损坏样本的真实文件集逐级压测；记录读取、解码、GPU、写盘、内存和端到端时长；断电/进程中断不重复丢项 |
| P1 | 复核效率 | 增加未复核队列、键盘快捷键、按分数/类别抽样、复核审计与筛选导出 |
| P1 | 数据治理 | 感知近重复候选、来源组管理、显式归档/恢复、异常文件清单、评估集重建流程 |
| P1 | 部署复现 | 第二台干净 Windows 机器安装验证；独立 CPU ONNX 环境已完成，后续补充 GPU 运行时分发、完整依赖哈希和全离线安装包 |
| P2 | 多用户或内网 | 鉴权、权限、配置化路径边界、操作审计、HTTPS、备份策略；重新评估数据库与作业队列 |
| P2 | 算法扩展 | 可选微调、增强、主动学习选样、开放集/未知类策略；通过固定业务评估集后启用 |

下一步建议先导入用户的真实业务图片。现有合成项目保留作回归演示，业务数据使用新项目，避免混用评估结果。
