          <section class="tex2jax_ignore mathjax_ignore" id="automm-for-image-classification-quick-start">
<h1>AutoMM for Image Classification - Quick Start<a class="headerlink" href="#automm-for-image-classification-quick-start" title="Link to this heading">¶</a></h1>
<p><a class="reference external" href="https://colab.research.google.com/github/autogluon/autogluon/blob/master/docs/tutorials/multimodal/image_prediction/beginner_image_cls.ipynb"><img alt="Open In Colab" src="https://colab.research.google.com/assets/colab-badge.svg" /></a>
<a class="reference external" href="https://studiolab.sagemaker.aws/import/github/autogluon/autogluon/blob/master/docs/tutorials/multimodal/image_prediction/beginner_image_cls.ipynb"><img alt="Open In SageMaker Studio Lab" src="https://studiolab.sagemaker.aws/studiolab.svg" /></a></p>
<p>In this quick start, we’ll use the task of image classification to illustrate how to use <strong>MultiModalPredictor</strong>. Once the data is prepared in <a class="reference external" href="https://pandas.pydata.org/pandas-docs/stable/reference/api/pandas.DataFrame.html">Pandas DataFrame</a> format, a single call to <code class="docutils literal notranslate"><span class="pre">MultiModalPredictor.fit()</span></code> will take care of the model training for you.</p>
<section id="create-image-dataset">
<h2>Create Image Dataset<a class="headerlink" href="#create-image-dataset" title="Link to this heading">¶</a></h2>
<p>For demonstration purposes, we use a subset of the <a class="reference external" href="https://www.kaggle.com/competitions/demo-shopee-iet-competition/data">Shopee-IET dataset</a> from Kaggle.
Each image in this data depicts a clothing item and the corresponding label specifies its clothing category.
Our subset of the data contains the following possible labels: <code class="docutils literal notranslate"><span class="pre">BabyPants</span></code>, <code class="docutils literal notranslate"><span class="pre">BabyShirt</span></code>, <code class="docutils literal notranslate"><span class="pre">womencasualshoes</span></code>, <code class="docutils literal notranslate"><span class="pre">womenchiffontop</span></code>.</p>

<section id="save-and-load">
<h2>Save and Load<a class="headerlink" href="#save-and-load" title="Link to this heading">¶</a></h2>
<p>The trained predictor is automatically saved at the end of <code class="docutils literal notranslate"><span class="pre">fit()</span></code>, and you can easily reload it.</p>
<div class="admonition warning">
<p class="admonition-title">Warning</p>
<p><code class="docutils literal notranslate"><span class="pre">MultiModalPredictor.load()</span></code> uses <code class="docutils literal notranslate"><span class="pre">pickle</span></code> module implicitly, which is known to be insecure. It is possible to construct malicious pickle data which will execute arbitrary code during unpickling. Never load data that could have come from an untrusted source, or that could have been tampered with. <strong>Only load data you trust.</strong></p>
</div>
<div class="cell docutils container">
<div class="cell_input docutils container">
<div class="highlight-ipython3 notranslate"><div class="highlight"><pre><span></span><span class="n">loaded_predictor</span> <span class="o">=</span> <span class="n">MultiModalPredictor</span><span class="o">.</span><span class="n">load</span><span class="p">(</span><span class="n">model_path</span><span class="p">)</span>
<span class="n">load_proba</span> <span class="o">=</span> <span class="n">loaded_predictor</span><span class="o">.</span><span class="n">predict_proba</span><span class="p">({</span><span class="s1">&#39;image&#39;</span><span class="p">:</span> <span class="p">[</span><span class="n">image_path</span><span class="p">]})</span>
