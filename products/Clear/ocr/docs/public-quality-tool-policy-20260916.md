# 通用工具接入约束

本轮按用户要求，以成熟通用工具构建能力，禁止按现有数据集打补丁。

- 结构解析使用 pdfplumber 0.11.10 的 `Page.find_tables()`。`table_settings={}`，所有容差为上游默认值；配置及工具源码哈希在首次运行前冻结于 `config/pdf-table-tool.json`。
- 不根据文件名、样本 ID、特定表头、特定金额或已知行列数选择算法，不针对现有或新增材料调整阈值。不以标注框裁剪输入。
- 自有代码只进行坐标系转换、上游格边界到跨度的无损表示、来源保存、候选复核和错误恢复。pdfplumber 不替换现有 OCR 文字；候选使用已验证的原生文字池。重叠候选逐个保留，程序不代替使用者选中“正确”表格。
- 上游有线表格默认算法对无线表格、嵌套背景框等会漏检或产生额外候选。这些输出及不可采用原因保留，不为提高报表成绩另加数据特判。PDF 表格候选仍需人工确认；表头语义没有从几何关系中猜测。
- 区域 OCR 的执行状态与内容状态分开。正常返回空文字生成可定位的复核项；引擎错误、取消仍为失败。空区域复核前不能通过 PDF 导出预检。保留页面结果不等于正确识别整页。
- 曾试写的自定义边线探测原型已撤回，产品源码中没有该实现；只在本机 `build/public-quality-20260916/withdrawn-prototype` 保存过程证据，不打入应用或源码包。

所有公开运行都是开发验证。新增上游公开回归 PDF 也是工具开发材料，不能称为独立封存测试。原始失败、重复文件、旋转变体和未解决复核项分别记录。独立业务质量和真实人工效率仍未测。

下一次更换工具、工具版本或使用其另一种公开模式时，需要先声明通用配置，再对完整固定集合重跑并保留全部失败；不能只补测表现变好的页面。
