**默认仍为 Paddle + local-v2。** 结构建议使用固定文字来源及 local-v3 归属/重算，TableFormer 与 RapidTable 可选择。没有自动结构采用，没有默认精确定位切换。

候选、建议及采用修订分表保存于同一数据库。决策绑定结果、修订、图像版本与内容哈希；同一请求可幂等重试。新增候选使旧检查和待处理建议失效。历史几何产物仅在图像版本及保存的文件哈希均验证通过时回收，否则需重新生成。结构接受后在原撤销历史中保存，重新计算对应，不额外调用 OCR。

原生建表只把实际使用的原生单位写入文字来源，不把重叠 OCR 加入其来源。PDF 导出依据不可变 token 快照校验编辑后文字，未经验证的元数据不能伪造原生定位；改字、删字或标题定位不确定时继续预检阻断。Excel 保留字面字符串、跨度、表头及页码/来源索引。
