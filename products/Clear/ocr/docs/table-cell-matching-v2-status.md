## 工作台行为

- 在「表格定位与人工绑定 · 实验性」中主动请求定位，采用 `local-v2`。几何不贡献 OCR 票，也不修改采用文字、复核状态和编辑历史。
- 有真实完整格候选且局部对应成立时显示单元格；只有真实文字坐标时显示「文字范围（实验性）· 尚无可靠完整格边界」；其余退到整表或全图并显示原因。
- 人工绑定优先。文字修订可保留稳定单元格身份的位置，但明确显示锚点来自此前快照；重新请求按新文字建立对应。
- 结构修改使对应失效；撤销不复活旧证据。旋转、裁剪和去弯曲等图像版本变化不能套用旧坐标。异步提交核对修订、全文、结构、活动版本、图像哈希与预测版本，取消任务不能提交。
- PDF 导出使用完整格证据或已有合法原生文字，不以显示边距充当定位证据。文字范围不能绕过完整格预检；多个逻辑格共用一个大框会被阻止生成重复文字层。

## 缓存与回退

模型候选缓存绑定当前图像/版本、区域、原始 OCR 输入、模型锁和 provider/坐标代码。对应缓存另绑定采用全文与结构、修订、算法代码指纹、策略版本/内容。候选 artifact SHA 校验通过后可纯 CPU 重放，无需加载 GPU。变更策略或对应代码不会命中旧对应缓存；两层缓存和历史原始 artifact 保留以供审计。

当前策略为 `config/geometry-matching-policy.json` 的 `local-v2-development-1`，`production_default=false`。回退时在新策略版本中设置 `algorithm=legacy`，保持实验状态，再主动请求定位；API 也接受显式 `algorithm`。选择切换不会删除新旧 evidence。v2 证据的策略或代码指纹不一致时被隐藏，旧 legacy 证据按原语义读取，人工绑定保持优先。**不要覆盖实验 run-lock、改锁后复用旧输出，或删除历史 artifact 来“清缓存”。**
