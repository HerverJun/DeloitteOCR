# 文档助手运维与诊断

本文件描述实验实现，不构成真实主控或目标机器验收通过声明。实际版本、测试日志和未测项见 [开发证据](../audit/ocr-agent-20260921-langgraph/latest-development-checks.json)。真实主控支持名单以 [资格状态](../audit/ocr-agent-20260921-langgraph/supported-configurations.json) 为准；当前为空。候选包和归档哈希以随交付提供的索引为准。

## 启用和关闭

应用读取便携包中的 `config/agent-policy.json`。`feature_flags.agent_enabled` 默认 `false`。实验候选包的“启动实验助手.cmd”通过包内运行时显式启用功能，普通启动入口保持默认关闭；两种入口都使用独立实验工作区。不要为启用助手直接改写已冻结候选清单或历史发布运行时。

维护人员可在命令行使用包内 `tools/start_agent_candidate.py --help` 查看 `--data`、`--review-only` 与 `--no-browser`。工作区带单实例锁；服务仅绑定随机本机端口。当前候选状态与已测试源码可能不同，应按交付索引选择经过对应验证的候选版本。

关闭功能开关不会降级数据库；普通 OCR 仍使用该程序版本支持的业务 schema。关闭 Agent 也不是恢复旧包的数据库回滚操作。

## 数据和凭据

| 数据 | 所在位置或归属 | 运维要求 |
| --- | --- | --- |
| 项目及 Agent 业务记录 | 工作区 `workbench.sqlite3`，当前 schema 14 | 包含请求回执、操作、授权、任务关联、事件、产物、决策和 inbox |
| 图执行状态 | 工作区 `agent-checkpoints.sqlite3` | 官方 SQLite saver 所有；不要手工写表或拼装任意 Command |
| 导出文件 | 工作区 `agent-artifacts/<project>/<artifact>` | 清单和哈希与业务 DB 对应；保留文件和活跃下载不能自动删除 |
| 主控 Key | 独立 AgentController 凭据存储，DPAPI | 不打包，不放入诊断；跨 Windows 用户需要重新配置 |
| 外部视觉 Key | 原视觉连接存储 | 不与主控混用 |

运行、模型和工具日志不应包含明文 Key。产物清单及任务记录本身可能含业务元数据，诊断分享前仍按项目的数据规则处理。

## 备份、迁移和回退

迁移前使用 SQLite backup API 生成业务数据库备份。schema 12→13→14 的测试包含实际旧库升级；未来版本数据库被拒绝写入。Agent 运行期间不能仅复制正在写入的主 DB 文件并忽略 WAL。

`Checkpoints.backup(destination)` 先等待图活动静止，再按统一锁顺序备份业务库与 saver 库，最后原子发布完整备份目录。该内部维护方法不接受模型输入路径。项目原件和产物目录需另做一致的文件备份；两个 SQLite 文件不能替代完整项目资料。

`restore_backup(source, new_directory)` 只恢复到新目录。恢复后再连接对应文件快照，核对版本、源文件和产物哈希。迁移到另一个 Windows 用户后重新配置凭据。

回退旧程序时使用与旧程序相容的迁移前工作区副本；保留升级后的完整工作区以便恢复。不要降低 `PRAGMA user_version` 或让旧程序打开新 schema。候选包的具体备份/回退位置应写入交付索引；旧发行版可执行文件回退仍需单独实测。

## 常见诊断

| 现象 | 检查和处理 |
| --- | --- |
| 助手入口未出现 | 检查 feature flag；默认关闭属于正常状态 |
| 依赖不可用 | 查看鉴权 `/api/agent/status` 的启动原因；普通 OCR 可继续；核对固定离线依赖是否装入正确副本 |
| 后台核对暂不可用 | status 中 `observer_error` 记录健康提示；检查数据库可写、磁盘空间和文件占用；过期租约会要求显式继续 |
| API 401 | 从当前应用托盘重新打开工作台；Bearer 不应放到 URL 中 |
| API 409 | 检查 generation、修订、范围或同 request ID 是否被用于不同内容；不要改 ID 绕过真实版本冲突 |
| 主控结果未知 | 保留模型请求记录和预算；核对后通过对应决定继续，不自动重发原 POST |
| 等待预算 | 先增加对应上限，再回复继续；PDF 区域任务也计入总额 |
| 后台长期无进度 | 默认 30 分钟无状态变化后等待用户决定；可继续等待或停止助手，不自动杀掉 OCR 或重新提交任务 |
| 重启后的 paused/interrupted | 通过对应运行“继续”；只恢复原创建任务，复用任务在原入口处理 |
| 产物不可下载 | 过期、文件缺失、文件或清单损坏分别处理；临时文件占用可稍后重试，不自动标成丢失；不能把磁盘上任意同名文件标成 ready |
| 旧决策回复被拒绝 | 范围、配置、revision、generation 或有效期已变化；重新查询后决定 |

已停止运行的后台 stage 若随后因区域预算不足暂停，当前开发 UI 尚缺完整后续增额恢复入口；应保留任务记录，通过新的明确范围运行处理，不能修改旧运行状态来绕过预算。

## 清理和停机

正常停机会关闭观察器和图任务，将未结束运行转为 interrupted。启动只做本地核对，不自动调用主控或恢复 OCR。等待用户和等待任务期间保留租约；租约过期推进 generation 和 fencing，拒绝旧执行者。

项目删除由原维护流程协调活跃任务和文件锁；业务会话删除写出 checkpoint 清理墓碑，再通过官方 saver 删除 thread。不能单独删除一个检查点来假装后台任务从未提交。

产物清理每批有上限，跳过活跃 run、保留产物和有效下载租约。删除前记录 deleting/expiring；磁盘操作中断后可重试完成，期间不提供下载。
