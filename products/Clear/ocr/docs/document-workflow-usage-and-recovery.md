# 文档工作流使用、更新与恢复

## 使用

解压 0.9.0rc1 完整包到新目录，双击“启动工作台.cmd”。模型/字体/独立 PDF 环境随包提供，不需要联网安装。保留旧 0.8.0rc2 包；新目录 E:\OCR-document-workflow-20260913\bundle。

“导入图片 / PDF”支持图片、PDF、多页 TIFF。文档树可选文档、跳页、搜索采用的已保存文字。PDF 默认 300 DPI；超像素上限时选择较低 DPI。页面按需展开，最多两个 CPU 页面工作器，GPU 串行。

自动模式保留可靠原生文字，OCR 扫描图片或未覆盖区域；仅原生模式不会消除待 OCR 区域；强制整页 OCR 用于明确重做。冲突区需要核对，不能因有页码认为正文已提取。原生结构预览须检查后采用，不覆盖原始结果与人工修订。

选表格单元格可定位原图；快速校对有候选、行列/邻接上下文，可切局部/整表及“在编辑器定位”。“补充表格定位”是实验性辅助功能，不确定时降至整表/全图。“人工框选绑定”记录人工来源。增删行列/合并拆分使旧几何失效；改变图像版本后重新定位，不能套用 UVDoc 前旧框。

导出 PDF 前保存，选择文档及页码。缺定位新文字、未完成 OCR、未确认冲突会列入预检；补定位/完成处理，或明确排除相关页面。每文档一份 PDF，多文档 ZIP；冻结采用修订，PDF 附件 OCR-sources.json 记录版本/页面/定位/重建原因，ZIP 带 sidecar。

可靠未修改原生页保留原页并追加必要文字层；原生改字、损坏映射或图像处理时重建该页。离线字体缺字明确报错，不联网补字。普通可搜索 PDF 不声明 PDF/A、PDF/UA 或签名有效，输入加密不让输出自动加密。密码只保留本会话，重启重新输入。

## 升级与恢复

默认项目位置 %LOCALAPPDATA%\OfflineOCR\Workspace，与应用分开。升级前退出旧托盘，复制整个项目目录备份，不同时用两个版本打开同一数据库。

schema 8 首次被本版打开前，SQLite backup API 保存 database-backups/before-v8-to-v9-*.sqlite3，再事务迁移 schema 9，失败回滚。历史图片/任务/结果/版本 ID 不变，原图不搬家。自动备份只备数据库，不替代项目文件完整备份。

回旧程序前保留完整 schema 9 副本，使用升级前完整项目目录；若用自动数据库备份，必须配套升级前对应项目文件，恢复至独立目录后启动旧版。旧程序拒绝 schema 9。不要修改 PRAGMA user_version 降版本，不覆盖历史，不混用新数据库与旧程序。

暂停/取消后对未完成阶段继续/重试；异常恢复等待明确继续，完成页不重做。加密文档先解锁。工作器异常落失败状态，修复驱动/输入/空间后重试，不手动改数据库。

## 离线核验

交付根目录有完整 ZIP、源码 ZIP、SHA256 及独立回执。“完整校验并启动.cmd”核对所有文件并检查运行环境；常规启动可复用本机完整校验缓存。PDF 依赖核验必须隔离：

```powershell
.\bundle\runtimes\pdf\python.exe -I -X utf8 .\bundle\tools\verify_pdf_runtime.py --lock .\bundle\config\pdf-wheelhouse.json --output .\pdf-runtime-verification.json
```

源码 scripts 保留环境重建、固定模型/字体、冻结数据、评测、恢复/容量/UI/PDF 审计和归档脚本。准备资产脚本只用于构建；运行期不下载。公开研究图片/标注在本机 build/document-workflow，WTW 数据不混入商业再分发包。效果复现须依清单重新取得许可允许的数据。
