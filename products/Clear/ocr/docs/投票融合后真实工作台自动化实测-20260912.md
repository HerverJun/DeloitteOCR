# 投票融合后真实工作台自动化实测

本轮使用 Codex 内置浏览器操作当前源码工作台，完成真实样本的识别、融合、校对、导出和恢复实测。发现并修复 4 个用户使用问题，逐项回到真实页面验证。没有发现本轮操作覆盖原图或原始识别结果。

## 环境与证据

- 基线提交 `997d139`；产品 `0.8.0rc2`，策略 `v5`。
- 独立入口 `http://127.0.0.1:8882/`，数据位于 `build/ui-audit-post-fusion-20260912/workspace`。用户原有 `8881` 服务及数据未改动。
- 使用当前 Python 源码和已安装离线引擎，识别结果没有模拟。修复回归使用当前 `frontend/dist`。
- UI 由 `cua_repl` 的 DOM、文件选择器、点击和输入实际驱动。浏览器清单接口失败后通过直接连接内置浏览器继续，没有换外部浏览器替代。
- 截图前确认其他任务空闲；截图后停止自动操作，保留页面，再整理证据与 Git。
- 只读 API 快照、文件哈希作为 UI 操作的辅助核对，不充当浏览器操作证据。

提交证据在 `audit/post-fusion-ui-20260912/`：来源清单、导出检查、状态摘要及两张内置浏览器截图。完整中间快照、原始样本、导出副本留在 `build/ui-audit-post-fusion-20260912/`。原始样本不进入分发包，启动凭证不写入报告。

## 发现与修复

| 问题 | 触发和修复前表现 | 修复及真实浏览器回归 |
| --- | --- | --- |
| 混合文字/表格首次复核失败 | 手写笔记包含表格；采用融合结果后首次保存即报“疑点当前内容已变化”。规范化后的 HTML 与原始字符串偏移、缓存值不同，界面还提供后端不支持的整段替换。 | 混合内容使用整篇文档目标，当前值和指纹读取同一保存修订，兼容旧工作区目标。整段含表格候选只作对照，界面提前禁用不支持的替换并引导普通编辑器。旧结果和新 CPU 融合均成功提交“暂不确定/保留当前”；编辑表格后正确过期并可重新复核。 |
| 重新加载后快速校对仍锁定 | 提交失败或两窗口决策冲突后，“放弃本次修改并重新加载”消除错误提示，但仍锁住上次提交。 | 重新加载时同步草稿与待提交请求，清除已经放弃的内部锁。两个内置浏览器页制造决策冲突后，重新加载并成功提交新的“暂不确定”。 |
| 新启动链接无法恢复失效会话 | 失效页面导航到同一路径的新凭证片段后仍无项目并报错；凭证仅在首次加载读取。 | 监听新启动片段、移除地址中的凭证并恢复连接；失效后暂停轮询，显示恢复入口。实测失效提示、新片段恢复项目、地址清除凭证均成功。后端鉴权保留。 |
| 损坏引擎 ZIP 提示笼统 | 上传非 ZIP 字节的 `.zip`，仅报“操作未完成，请重试或在托盘查看日志”。 | 将其作为输入错误，提示 ZIP 无效或损坏、应重新获取完整包；清理暂存并保留现有引擎。重启当前源码服务后重新上传同一坏包，提示正确。 |

## 数据与导出核对

10 个原文件和 19 个图片版本均匹配数据库 SHA-256。本轮较早快照中的 27 份原始识别对象与最终对象逐份比较，全部未变；修改保存在校对数据及历史。

8 份导出保留的是实际 `/api/export` 返回的原文件，复制前后 SHA-256 相同。Excel 中前导零、20 位编号、负数字符串和公式样式文本均为字符串，没有公式单元格；合并关系及多个工作表保留。融合清单、证据文件 revision 一致，来源与复核摘要完整；仅已确认正确限制范围。

内置浏览器下载事件等待超时，因此本轮**不证明操作系统下载目录最终落盘成功**。测试服务只包装 `build_export`：调用原函数一次，复制返回文件后原样返回，再正常响应和清理；不修改业务参数或输出。此限制与服务端文件内容检查分开记录。
