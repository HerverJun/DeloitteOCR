# 数据工作台：当前主要功能

这是功能开发版本。完整发行包与正式综合验收按后续计划执行。

## 启动

当前开发运行目录已提供独立 platform-venv 和 data-venv，无需安装 OCR/分类依赖。

1. 在 apps/portal 执行 pnpm build。
2. 在仓库根目录执行 powershell -NoProfile -File scripts/start_data_workbench.ps1。
3. 打开 http://127.0.0.1:8766/apps/data。也可从门户“应用”页的数据工作台卡片进入。

脚本默认使用 E:/project/platform-dev-runs/dev-20260925-001 下的运行时与独立 data-workbench-live 数据目录。可传入 -RunRoot、-DataDirectory 和 -Port；不会更改旧 OCR/分类用户项目。

## 使用

- 不需要平台工作空间：直接新建数据作业，或选择已有作业继续。
- 上传左表、右表：CSV、XLSX、Parquet。CSV 可设置编码/分隔符，XLSX 可选择工作表；表头行 0 表示无表头。首次 XLSX 导入默认第一张表，选择其他工作表后点“按设置重新导入”。
- 六类清洗：去空白、列改名、值映射、类型转换、筛选和重复识别。预览保留原行号，悬停查看单元格类型、原始值和警告。
- 历史版本保留，可撤销或切回；配方可命名保存，通过明确列映射应用到另一份表格。
- 明确选择左右匹配键和比对列；金额容差、空值、文本比较策略均可选。重复键单列为歧义，不自动多对多配对。
- 结果按相同、差异、仅左、仅右、左右重复键分页显示；可选择旧比对记录。
- 可导出当前清洗表，或生成比对结果的 CSV/XLSX/Parquet 与 summary/provenance 清单；固定版本可重复下载。
- 作业和文件保存在本地，页面刷新可继续。后台独立分析进程支持取消；取消或异常保留最后成功版本。服务异常退出后未完成操作标为中断，可明确重试。

当前边界：单文件 64 MB、最多十万行/256 列/一百万单元格；单个操作 180 秒上限。一次只运行一个分析进程。复杂 Parquet 嵌套/二进制列暂不接受。CSV 对公式式文本加安全前缀，原始字面值与类型在来源清单保留。

工作台现在作为门户内置入口运行；统一成果中心发布、正式应用分发登记、目标设备性能和完整资格验收仍属于后续工程。
