# 项目与 Clear 工具的简化方向

2026-10-03，revision 24 / Q01。用户明确将日常操作收敛为“选择项目 → 选择 Clear 工具 → 开始处理与输出”，优先快速落地和稳定。

## 日常流程

1. 选择已有项目，或只填写名称新建项目。
2. 选择 ClearData、ClearClassify、ClearOCR 或 ClearForensics。
3. 在工具中导入资料，保留必要处理设置，直接处理和下载输出。

首页使用这三个步骤，主导航为“开始处理、项目、Clear 工具、输出”。原审计底稿、统一待办、资料库、模板批次、运行任务和设置进入折叠的高级功能。程序、调查证据、人工声明和编复核不再是普通工具使用或下载的前置条件。

## 实现边界

- 轻量项目复用现有 workspace 存储与标识，只填写名称，不引入另一套项目数据库。前端显示“项目”，原 API 和 workspace 查询参数继续使用。它与高级审计底稿中的 AuditProject、OCR/分类内部原生项目是不同对象。
- 新数据作业持久绑定当前项目；按项目筛选已有作业。创建请求保留稳定身份，响应丢失后重试同一请求。旧未归属作业保持原记录，不自动迁移或猜测归属。
- 数据输出由成功导出任务和项目归属直接查询。浏览器关闭或刷新后仍能在输出页面找到文件，不要求先归集证据或编制底稿。既有文件完整性校验和下载接口继续复用。
- OCR/分类启动完成后进入简化入口，显示当前项目的已关联工具作业。首次使用沿用项目名称，分类只需首次填写实际类别；正常使用在原生工具内上传、处理和下载。保留现有启动核实及单次导航票据。
- 原生创建响应不确定时先读取已有关联，未确认前停止新的创建，避免重复作业。简化导航票据返回工具 start 页面，高级 workflow 返回路径保持原行为。
- 图像取证使用默认经典工具，处理设置和人工审阅说明可展开；生成报告即可查看和下载，人工审阅保持可选。已归集的图像报告在输出中心可见。

## 优先级调整

Q01 是用户主动调整产品方向后的业务简化，不以此前 21 项审计流程任务的完成比例衡量新流程。旧计划及 16/21 已完成记录保留为历史。后续优先处理工具安装与启动、项目隔离、异常恢复、可用输出和独立交付；不再扩展复杂证据审批，也不要求六类完整审计任务记录作为日常工具使用前提。

当前仍是本机源码预览；独立候选运行时及原生实际冷启动资格按实际安装状态办理，不将界面简化等同于安装完成。只执行本次改变的项目、入口、恢复和输出检查，不重复图像算法、模型或完整审计流程。
