# 平台工具接入与交付

Agent 使用平台登记的业务工具。提供目标、资料和交付要求后，它可以发现能力、按需加载操作定义并组合原生服务；普通分析、必要准备及派生成果继续执行。模型轮数、工具次数和整体时长默认不限，单次模型请求超时及停滞检测继续生效。

## 目录和资料范围

“平台工具”展示实际绑定、准备条件及阻碍。目录与可执行操作同源，当前源码共 120 项操作：原 106 项名称全部保留，新增人脸、音频、印章、CAT-Net 的提交、准备、结果读取、导出、归集、转换、重试和用户动作衔接。准备成功只证明运行环境可用，不能作为业务任务成果。

人脸参考范围必须由用户明确选择；默认没有参考授权。提交时固定所选参考的版本、模型和来源，后续参考库变化不会改变旧结果。仅查看其他任务结果不能获得控制该任务作业的权限。

## 等待、恢复和控制

原生作业提交后由任务层等待权威状态，等待期间不要求模型轮询。关闭页面不影响执行。响应丢失先查询原请求，不能更换身份重复创建任务。服务重启后核对进程所有权、执行代次及文件完整性；无法确认的结果保持待核实。

暂停保留已提交作业。“停止后续步骤”与“停止并取消本轮作业”是独立操作，取消须有原生终止回执。Agent 默认只控制本任务提交的作业。

## 草稿、核准和成果

算法结果未经人工复核时保持草稿标识。印章转换保留原始文字、候选字段、置信信息及区域来源；每个 Agent 任务拥有独立的数据核对工作区。数据结果、证据、发现和底稿继续追溯原始复核状态，不能通过重新导出移除草稿身份。

交付策略可选择自动、仅草稿或需要核准。自动策略从保存的用户目标和后续要求解析；模型摘要、资料内容和计划不能降低要求。先草稿、核准后正式的目标可以分批展示草稿，正式交付等待当前结果版本的实际用户答复。核准发生后，沿原任务继续，不重新提交已完成分析。

新结果引用固定作业、代次、结果哈希、复核版本、模型及来源。复核或重试生成新引用，旧链接继续指向原内容。交付检查读取真实文件、校验哈希和原生状态；音频另检查时间范围。算法执行成功与业务结论成立分别表达。

## 诊断与回退

诊断视图保存完整操作身份、模型请求、引擎/模型版本、恢复与交付检查。契约测试、处理器测试、真实算法运行和真实模型自主任务分别计证据，工程测试不计自主业务成功。

新增结果、授权及复核记录写入前登记 `agent-multimodal-v1`。不支持该特性的旧程序拒绝打开已升级 DATA。回退须使用保留的 0.12.1 发行与切换前的一致性备份。所有源码、依赖、模型、DATA、缓存、备份及证据均保存在 F 盘。
