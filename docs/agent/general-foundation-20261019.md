# 通用工作能力与审计工具

本次升级的顺序是先恢复日常工作能力，再按任务需要使用审计工具。用户仍通过同一个聊天入口提问、提供文件和追加要求。

普通问答可以直接结束。文件任务可读取、搜索、编辑文件，运行 PowerShell、Python 和已登记技能脚本；已有 Python 库可用于特殊清洗、精确计算、XLSX 或图表生成。任务使用 F 盘专用工作目录和输入副本，脚本的临时、缓存与扩展包也在 F 盘。实际文件输出会固定版本、核对字节并提供下载。

常规图片或 PDF 文字提取使用 `extract_text`；多文件多列清洗使用 `data_clean_files`，内部复用已有原生服务。其它专业工具通过一次 `tools_search` 加载即可调用。普通任务不要求先建正式档案、维护审计计划或显式发布成果。需要证据、发现、底稿、指定模型推理或更细的工具操作时，再启用相应能力。

从已核实结果编制新底稿时，`audit_create_workpaper` 复用现有证据、发现和导出服务，一次完成固定证据、保存 Agent 草稿、生成可编辑文件及正文哈希读回。模型提供真实来源和分析，服务传递内部 ID。导出中断时保留已保存发现并提供只续缺失步骤的引用；同一操作恢复不会重复增加发现版本。已有发现修订继续使用原工具。

OCR 任务内选参使用少量代表样本比较方案，再复用成功样本处理整批，只补失败项。有真值时比较实际字符误差；没有真值时仅报告结构、覆盖或规则等可观测指标。任务选参不等于训练专业模型，也不会自行修改全局默认配置。

运行期间可以追加要求。暂停、停止后新目标和安全边界重启均保留原任务记录；未知模型回包或未知业务写入会保留原回执，界面明确提供继续或核实操作。后台作业可跨轮保留，等待原生服务不需要模型反复轮询。会话冷备恢复到新的 F 盘目录后，工作目录、Python 和写入权限跟随恢复目录，原会话日志保留并追加真实目录变更记录。

设置页可配置 MCP 连接及主控图片输入。Web fetch、MCP、子助手和图片能力按连接、模型与实际资源提供；未配置的搜索服务不宣称可用。本地 MCP 进程与普通命令使用 DSH 的受限写入边界，凭据通过既有加密存储管理。

审计证据、来源、原生作业状态和下载核验继续有效。明确要求正式复核时，仍需真实用户对固定版本确认；用户不确认则保留草稿。聊天中的证据视图提供固定原文及来源，完整引擎载荷留在原始证据记录中，避免每轮重复发送字框等底层数据。

新运行通过 `clear-general-agent-v1` 区分语义，已有会话仍兼容旧的回答、发布与工具加载记录。DATA 在实际写入新语义时登记 `agent-general-v1`；回退应使用切换前的一致性备份及对应发行，不让旧程序直接打开新格式 DATA。
