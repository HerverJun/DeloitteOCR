# Agent 上下文与 Skills

Agent 继续以“用户目标 → 选择已注册工具/模型 → 执行并读取结果 → 决定下一步 → 交付成果”运行。此次更新修复首句聊天因工具契约过多而被本地拦截的问题，并增加可信环境说明和可复用业务技能。

## 上下文

首轮只加载 14 个核心工具。`tools_list` 是轻量分页目录，不会激活目录里的所有工具；`tools_describe` 明确加载下一步需要的参数契约。上下文不足时回收较早且无关的工具，保留核心、当前批次和新请求的工具。完整契约只进入原生工具字段，避免在历史里重复发送。

每次模型请求都对最终 HTTP JSON 计量，分别显示平台说明、运行环境、Skill、工具契约、用户消息、工作事实、工具结果、模型续接和协议封装，并单列输出预留。配置模型是自定义别名或没有本地可用的匹配 tokenizer 时，明确显示字节估算；已知编码仅从验证过的 F 盘缓存读取。估算不代表供应商实际 token 用量或真实模型窗口，实际 usage 独立显示。

连接设置保存及单独探针会先检查生产首轮核心工具、环境和技能名录，再验证原生工具调用协议。连接探针不发送项目资料。实际任务和激活技能仍在每次请求时重新检查预算。超限说明占用最大的组件，不再统一要求用户缩短一句普通聊天。

## 环境与工作事实

动态可信说明包括平台身份、配置模型/协议/连接版本、Windows 本机执行、专业模型分工、项目/会话及人工接管和资料授权边界。主控通过注册工具调用本地服务，不直接获得 cmd/PowerShell。

不注入 API Key、原生服务 token、完整进程环境、端点地址或无关本机路径。供应商返回的模型身份与配置 ID 分开记录。项目当前规则、目标和安排完整保留；历史讨论和操作采用有标记的有界事实，完整记录仍在原账本。大型表格和报告以固定引用分页读取。

`session_read_history` 可按事件目录和正文偏移读取完整的旧目标、讨论及交付，包含固定正文 hash；它只读取当前会话。批次和成果回执的发送摘要保留身份、版本、状态、覆盖与原始引用，避免把内部整份元数据再次复制为“必要事实”。

模型请求事件记录环境字段/版本、工作事实版本、实际可见工具和已激活技能版本。压缩仅作用于发送副本，原始会话、证据、操作回执和工具调用/结果配对不被改写。

## 技能

首页“Agent 技能”可查看可用/已激活技能、来源、兼容状态和固定版本，按需读 `SKILL.md`、参考资料和模板。Agent 可通过 `skills_list`、`skills_activate`、`skills_read_resource`、`skills_deactivate` 自行选择和切换，用户也可明确启用。新建项目后可直接查看目录，不需要先发起模型请求。

默认根为 `config/skills`；额外平台/工作区根由服务器的 `config/skills-registry.json` 明确登记，全部必须真实位于 F 盘。业务资料不会自动注册为指令包。登记使用 Agent Skills 的 `SKILL.md`/YAML 格式，并校验名称、兼容要求、资源路径和容量。

首批四项是付款台账核对、票据 OCR 与台账比对、分类标注与训练准备、证据整理与底稿。它们指导调用现有服务，不生成替代业务脚本。第一版只支持正文、references 和 assets 模板；scripts 可登记但不执行，也不会取得 shell 权限。

`allowed-tools` 只能缩小可调用集合；多个带限制的技能取交集，核心发现/退出机制仍可用。每次实际调度再次检查，因此同批次激活技能也不能越过其限制。切换业务时先停用无关技能。

激活时固定正文及全部资源字节、内容 hash、来源和使用记录，保存在既有 Agent SQLite 库内。重启或源文件变更后继续使用已固定版本；更新必须明确启用当前新版本。界面显示源变更，资源读取不会悄悄替换历史内容。

已收到的模型回复按原输入状态恢复，保留原请求身份及实际工具集合，不因当前技能源名录变化而重发。新目标、资料范围、项目规则、固定技能版本、主控配置或宿主工具契约变化仍会冲突；回包未知不自动重发。旧版没有输入状态记录的请求继续按原完整请求指纹保守校验。

## 打包与恢复

打包包含技能目录、服务器登记配置及 `skills.json` 清单，校验所需工具和资源版本，不依赖 Codex 个人技能目录。工作区备份既有 `agent` 目录即可覆盖技能快照和使用账本。所有运行、缓存、测试资料、日志和交付包仍在 F 盘。

实现记录和请求结构证据位于 `F:\OCR\output\agent-context-skills-development-20261005`。主控协议验证使用本地模拟端点，没有发送远程主控请求。数据核对、结果读取、证据和底稿走真实业务工具；四项技能接续使用合成资料。原生兼容回归还实际执行本地分类训练/推理、OCR、PDF 与取证算法。通过这些工程检查不代表真实审计资料的识别准确率或训练质量。
