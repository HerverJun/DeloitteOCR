## 事实核对与修订

- 正式 Clear v0.10.0 OCR 运行代码来自发行根 `ocr/src`，网页来自 `ocr/frontend/dist`，schema 为 17；底层 `program/bundles/ocr` 中 schema 15 的旧源码/网页不是实际入口。根仓独立研发线为 schema 18。
- 正式 Agent 默认关闭；项目概况的 Agent 概览接口也可能不可用。资料、成果、手动工具和独立正式档案流程仍按自身服务使用。
- 门户 OCR 归集需要共享资料交接记录。说明书已区分快捷原生导入/下载与“资料库 → 固定集合 → OCR 交接 → 归集”的完整路线。
- 资料库搜索限文件名、来源与标签，不声称正文全文检索。
- 平台备份不自动包含原生 OCR/分类数据，三部分数据及业务模型须分别核对和备份。
- 原仓 `.gitattributes` 保存为 `.gitattributes.source`，防止分类工程换行规则改写快照字节；许可 METADATA 中的 RST 下划线按来源保留，未当成合并冲突修改。
