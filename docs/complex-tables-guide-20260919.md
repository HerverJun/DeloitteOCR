# 复杂表格专项使用说明 · 0.13.0rc1

本版在现有结构复核中增加可审阅的本地候选、外部候选仲裁和财务疑点。所有修改仍须人工采用；没有扩大自动采用范围。旧版 ZIP 不包含这些功能。

## 本地结构复核

1. 导入并识别或提取文档，采用需要校对的结果，保存编辑内容。
2. 打开「结构复核」，点击「检查已有候选」。原图在左侧；右侧展示当前结构、候选、受影响行列、含数字的变更格、未归属文字和人工修改冲突。
3. PDF 原生表格工具保留原有候选；当存在大块填充底纹时，另提供「底纹过滤实验」候选。过滤只排除非描边、宽高均大于 3 PDF 点的填充矩形，保留细线与原始坐标。此规则可能不适合用大色块表达边界的表格，应核对原图。
4. 合并／拆分只使用来源支持的矩形网格与完整文字片段。缺失格位不会被压缩；一个合并框不会作为多个精确子格框。重复金额没有独立空间与行列证据时继续保留歧义。
5. 「待核对空值」不等于真实空白；「疑似漏字」表示存在未归属的重叠文字。核对原图，必要时使用已有识别入口重新取证。纯结构建议不添加新 OCR 文字。
6. 接受、保留、拒绝或暂缓仍使用原有入口。人工改字和绑定框优先；冲突未解决时不能采用。采用后使用编辑器「撤销／重做」。重新打开项目不会自动采用任何建议。

「表格辅助定位」可选「复杂表格空间对应（实验）」（local-v4）。默认仍是 local-v2。新策略使用空间索引、已验证行列锚点和有界冲突检查；预算耗尽时保留已完成全部约束验证的锚点，其余格降级。大表的最终结果组装也需要时间，不能把 200ms 搜索预算当作整页端到端保证。

## 外部结构仲裁

在「视觉审校 → 配置外部 API」设置现有单连接后，回到结构复核，展开「外部 API 结构仲裁（实验）」。勾选发送确认后提交。发送内容包括当前页面 PNG、当前表结构、有限候选的行列与跨度、来源文字 ID 和固定文字池。当前版本使用整页上下文，不从待判断候选猜测局部裁剪；整页文字不够清晰时模型应弃权。

首版只支持**选择已存在且通过本地硬校验的候选或弃权**。合并／拆分须先由本地形成候选；API 不能任意改写整表、文字、金额、坐标或跨度。结果显示在当前结构复核内，「查看推荐候选」只切换预览，「接受结构建议」才改变内容。导出来源记录保留关联任务和人工采用依据。

每个表、每个修订最多提交 2 次，每次至多 6 个候选、1,000 个候选格、合计 2,000 个文字片段、40,000 字符；整页发送图像最多 1,048,576 像素、最长边 1,600，单次网络超时不超过 90 秒。证据超过上限时本地拒绝，不自动删减来源。提交失败也占用当前修订的提交额度，防止不确定状态下重复调用。

外部任务复用独立网络队列，可与本地 OCR 分开运行。支持取消；超时、限流、截断、非法 JSON、重复文字引用和过期候选不会产生可采用的新修改。已尝试发送的结构任务不自动重发，重新提交须使用新的请求。配置、图像、候选或内容变化后需要重新提交。启动、打开项目和读取连接不调用供应商。断网时本地核对、人工编辑和导出仍可使用。Key 仍由 Windows DPAPI 保存，不进入结构快照、日志或报告。

## 财务一致性疑点

结构复核底部可展开财务疑点。当前检查包括明确合计标签及连续非嵌套明细、年度重复列、编号列异常、小数位差异、负数括号、百分号、币种和明确金额单位。金额采用十进制计算，显示原值、关系、明细和、差额及舍入范围，不改写原文。

破折号、真正空白、缺失、编号和数字分别处理。未知单位、混合币种、嵌套小计、合并格范围、带注释的金额及不明确关系保留为不确定，不能据此认定原文错误。当前不解析任意财务公式，也不自动修复合计。

## 验证范围

运行证据位于源码工作区 `audit/complex-tables-20260919-01/`，输入与逐项实验在独立 `build/complex-tables-20260919-01/`。公开原始研究文档、测试项目和个人凭据不进入交付包。总结见 [专项结果报告](complex-tables-results-20260919.md)。

本轮真实公开 PDF 为小规模开发／回归材料，Agent 视觉核验不等于人工签核或官方独立真值。历史 TableFormer/Paddle 重放不等于新模型推理，也不能证明中文财务整页效果。正式 100 文档／120 表／6,000 格及高风险分组目标没有降低。

OpenAI 与 Anthropic 均有本机模拟协议和产品链路验证；本轮没有使用真实付费服务，真实 API 净收益、调用费用、实际人工节省时间及用户目标设备 GPU 推理均未测。低于质量与性能门槛的机制保持实验状态。

## 复现与补验

- `scripts/complex_table_run.py --init`：校验已有 run 身份，不覆盖历史目录。
- `scripts/prepare_complex_tables.py collect`：复用哈希一致的成功下载；失败来源不进行同方法空重试。
- `scripts/evaluate_complex_tables.py --run <新运行编号>`：同输入历史重放；旧目录代码哈希不同会拒绝覆盖。
- `scripts/measure_complex_mechanisms.py --name <新回执名称>`：合成成本与归属检查。
- 使用已验证 service Python，执行 `scripts/run_complex_checks.py --suite full --name <新回执名称>`；脚本将当前 `src` 放在导入路径首位。
- `npm.cmd --prefix frontend test`、`npm.cmd --prefix frontend run build`；构建后执行 `scripts/audit_complex_table_ui.py --output <新目录>`。浏览器采用外部无头 Edge，关闭 GPU 与 GPU 合成。

正式补验须新增未曝光的文档／模板组、合格参考标签和真实扫描／照片，冻结后再运行。真实服务补验须使用已有授权连接和公开合格材料；不得把协议模拟或脚本点击时间冒充真实收益。
