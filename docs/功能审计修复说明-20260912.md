# 功能审计修复说明 · 2026-09-12

对应 `build/functional-audit-20260912/功能审计报告.md` 的 6 项缺陷，已修复当前源码并构建前端。

| 审计项 | 修复后的行为 |
| --- | --- |
| P1 撤销跨图片回写 | 保存、撤销、重做和重新加载共用请求队列；历史和重新加载请求固定结果 ID、检查加载代次。切图、切项目等待在途编辑操作完成，随后编辑写入新图片的结果。并发界面操作按计数维持忙碌状态，期间禁止文字和表格继续编辑。 |
| P1 HTML / Markdown 混排丢表 | 两种表格按原文位置合并解析，记录来源范围和摘要；TXT、Markdown 导出共用这些范围替换，保留表格前后的换行和普通文字。 |
| P1 汇总 Excel 静默遗漏 | 单结果、逐图片和汇总 Excel 都先检查全部选中结果；缺少结构化表格时阻止导出并列出图片名称。写文件时再次校验，失败清理临时导出目录。结果逐个读取，避免累积整批原始模型输出。 |
| P2 键盘操作与表格选区脱节 | 单元格通过 Tab 获得焦点时同步选区和地址；删行、删列按当前单元格执行。Shift 点击仍保留原选区锚点。 |
| P2 复制返回旧表格文本 | 复制先完成待保存校对，再调用与 TXT 导出相同的接口，使用合成后的文字和表格内容。 |
| P2 迟到导入污染项目选择 | 导入完成后核对项目 ID 和切换代次；跨项目完成时只保留目标项目中的导入数据并提示，不覆盖当前活动图片或选中项。离开后再回到原项目同样受保护。 |
