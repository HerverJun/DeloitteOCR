# 纸页工作台使用说明

## 打开与退出

将完整 ZIP 解压到本地目录，双击「启动工作台.cmd」。启动时先检查驱动、GPU/显存、项目磁盘、全部文件 SHA-256 和运行库加载；状态窗口显示进度。文件校验时间受磁盘速度影响，完成后打开服务。开始识别时才加载模型，不需要联网下载。每次启动分配本机端口和会话凭证，外部网站无法调用识别接口。

项目默认保存于 `%LOCALAPPDATA%\OfflineOCR\Workspace`。关闭浏览器后，后台和队列继续运行。系统托盘「纸页」菜单可打开工作台、查看状态、打开项目目录和日志、退出。关闭状态窗口会隐藏到托盘。只有退出工作台才结束后台。不要仅删除应用目录来清理项目。

需要指定独立项目数据目录时，可运行 `launcher\OfflineOCRLauncher.exe --data "D:\我的 OCR 项目"`。同一数据目录只允许一个启动器实例；四引擎共用单 GPU 锁。

## 识别、版本与对比

1. 新建项目，导入文件、整个文件夹，或将图片/文件夹拖入界面。支持 JPG、PNG、BMP、单页 TIFF、WebP、HEIC/HEIF；损坏图片、超过 8000 万像素或 128 MB 的图片会明确提示。多页图片须先拆页。
2. 选择「照片文字」「手写」「表格」或「模型对比」。默认模型是操作预设，不代表准确率排名。PP-OCRv6 提供文字与坐标，不生成结构化表格。
3. 可缩放、拖动、旋转、裁剪、增强对比度，或按左上、右上、右下、左下选取透视四角并拖动调整。去弯曲使用随包 UVDoc，作为 GPU 队列任务执行。处理生成新版本，原文件和哈希始终保留。「查看原图」和版本选择器用于前后对照。
4. 区域重识别会保存所框选区域为新版本，再使用当前所选引擎识别。不同版本的坐标不会叠加混用；结果提示「另一图像版本」时可点击定位。
5. 模型对比保留独立原文、耗时和差异行，点击「采用结果」选择后续校对与汇总导出的结果，不自动混写模型输出。文字区域列表可定位原图中的对应坐标；没有坐标的项目不会伪造定位框。

## 校对与导出

文字支持编辑、查找、复制；结构化表格支持单元格编辑、标题、行列增删、合并与拆分。按住 Shift 点击两个单元格选择矩形。跨越已有合并单元格时须完整选择。合并保留被选单元格文字，拆分后文字保留在左上单元格。

编辑自动保存，切换项目、图片、识别结果和导出前会先保存。撤销/重做按保存的编辑历史进行；短时间连续输入会合并为一次保存。保存失败时不要关闭页面，可重试；发生多窗口编辑冲突时会拒绝过期写入，重新加载将丢弃当前未保存编辑。原始识别 JSON 与人工校对独立保存。

TXT/Markdown 使用校对文字及校对表格，JSON 同时包含原始结果与人工修改。Excel 将各表放入独立工作表，保留合并、空格、前导零和长编号，全部单元格按文本写出，不推断公式。没有结构化表格的结果不能导出 XLSX。勾选「导出选中图片采用的结果」后，默认每张图片生成独立文件，多张打包为 ZIP；每张图片中的多个表分别放入其工作簿的工作表。需要合并时再勾选「汇总为一个工作簿」。批量导出逐个读取已保存结果，临时 ZIP 写在项目磁盘，下载结束自动清理。

## 队列与恢复

模型按组顺序处理，GPU 同时只运行一个引擎。暂停等待项不会中断正在处理的图片；需要中断当前项时点击取消。失败或已取消项可重试，已完成项不会重做。退出或异常终止后，原来正在运行的任务标为等待继续，原来排队的任务暂停，用户手动继续后才运行。

在「批次预处理」选择保留图像、增强对比度、旋转或组合预设。创建批次时固定图像版本、预处理参数和引擎包版本；之后切换引擎包不改变旧任务。处理后的版本可与原图对照。图像解码最多同时进行两项，GPU 识别串行执行。显存不足会明确记录失败并释放引擎，可在释放显存后重试；不会自动降低精度。

## 项目空间

左栏「项目占用与清理」显示原图、处理版本、任务输出和缩略图占用。先暂停或取消任务，并等待当前项退出，再输入完整项目名称确认删除。清理永久删除该项目的文件、结果及人工校对，操作前先导出或备份。其他项目、共享模型和诊断日志保留。文件或数据库操作失败时恢复原文件；已提交删除但未释放的文件在下次启动继续清理。

## 离线引擎包

「引擎管理」导入完整 ZIP，内容须包括模型权重、独立运行时、适配器、配置、依赖锁和 SHA-256 清单。暂存阶段只校验并解压，不执行包内代码。核对来源、名称、版本和哈希后点击「启用此引擎包」，系统再次校验，并实际检查依赖和模型识别，然后切换。哈希只能证明内容一致，不能证明发布者可信。

启用前须等待当前识别结束，可先暂停等待任务。新任务使用启用版本；已有任务、历史结果和人工校对继续关联原版本。版本下拉框可切回随应用内置版本或已安装版本。旧版本保留，不会因回退被删除。完整包需要同时容纳 ZIP、暂存文件和保留版本的磁盘空间；不应手工删除仍有关联任务的版本目录。

## 验收范围

本机专项证据包括真实四引擎闭环、20 次加载卸载与 500 张合成压力样例，后者用于工程稳定性。公开真实图片的区域评测、目标 A4000、另一台无开发环境 Windows 和内网样本的状态以《最终阶段验收矩阵》为准；本机数据不替代目标机结论。
