# 项目文件存储规范

生效日期：2026-10-02。适用于本机上的 OCR、Clear 系列平台及关联开发、测试和交付工作。

**所有项目文件均只能在本机 F 盘落盘，禁止到处乱存。** 本项目主目录为 `F:\OCR`；其他仓库和隔离工作树也只能使用本机 F 盘内明确登记的目录。其他盘符、网络共享和云同步目录不得作为项目文件的写入目标，工具默认位置和临时文件不例外。

## 1. 文件范围与目录安排

约束包含源码、文档、配置、脚本、Git 元数据、工作树、依赖、虚拟环境、模型、下载、输入副本、数据库、凭据、锁文件、日志、缓存、临时文件、中间产物、截图、录屏、报告、导出、备份和交付包。只读使用盘外已安装的工具或历史资料，不授权向这些位置保存项目文件。

| 用途 | 本机目录约定 |
|---|---|
| OCR 源码、文档与配置 | `F:\OCR` 下对应的 `src`、`frontend`、`docs`、`config` 等目录 |
| 关联平台与分类仓库 | `F:\project\<仓库名>`；实际使用前登记路径，禁止覆盖非空目录 |
| 隔离工作树、运行状态和检查证据 | `F:\OCR\output\<任务名>\worktrees`、`runs`、`evidence` |
| 构建、依赖、虚拟环境与模型 | `F:\OCR\build`、`.venv`、`.pnpm-store`、`wheelhouse`、`models` 等用途明确的目录 |
| 工具缓存与临时文件 | `F:\OCR\.cache\<工具名>`、`F:\OCR\temp\<任务名>` |
| 应用数据、锁、凭据与校验记录 | `F:\OCR\output\<运行名>\workspace` 与 `.cache\localappdata\OfflineOCR`；不得复用用户真实工作区进行测试 |
| 截图、录屏、报告、导出、备份和交付包 | `F:\OCR\output\<任务名>` 下按用途分目录 |

目录表是新写入的约定，不表示目录已经创建或历史文件已经迁移。已登记且用途明确的其他本机 F 盘项目目录可以复用，禁止在 F 盘根目录随意散放文件。

## 2. 执行前必须确认实际落点

1. 将工作目录和每个输入副本、输出、日志、下载、备份、数据库路径解析为绝对路径，确认实际目标位于本机 F 盘。检查符号链接、junction、挂载点及工作树的真实目标；Git 工作树关联的仓库元数据也必须在 F 盘。
2. 显式设置工具支持的缓存、临时、浏览器 profile、下载和应用数据目录，并让所有子进程继承。不能因为命令在 `F:\OCR` 运行，就假定其默认缓存也在 F 盘。
3. Python/pip、npm/pnpm、模型下载器、浏览器、构建器及文档/图像工具分别核对；不支持指定 F 盘写入位置的工具，改用可控制路径的方式。默认 Codex 工作树和可视化目录若在 C 盘，不得用于本项目产物。
4. 运行后核对本次文件清单与实际落点，将使用的 F 盘目录记入运行记录。发现盘外写入先停止相关写入，查明来源；不得擅自删除或搬迁旧资料来掩盖问题。

可在专用 PowerShell 会话中配置当前进程及子进程，以下仅是通用起点；仍须核对各工具自己的写入配置：

```powershell
$taskStorageRoot = 'F:\OCR'
$taskTempRoot = Join-Path $taskStorageRoot 'temp\current-run'
$taskCacheRoot = Join-Path $taskStorageRoot '.cache'
New-Item -ItemType Directory -Force -Path $taskTempRoot, (Join-Path $taskCacheRoot 'localappdata'), (Join-Path $taskCacheRoot 'appdata') | Out-Null
$env:TEMP = $taskTempRoot
$env:TMP = $taskTempRoot
$env:LOCALAPPDATA = Join-Path $taskCacheRoot 'localappdata'
$env:APPDATA = Join-Path $taskCacheRoot 'appdata'
$env:PIP_CACHE_DIR = Join-Path $taskCacheRoot 'pip'
$env:npm_config_cache = Join-Path $taskCacheRoot 'npm'
$env:HF_HOME = Join-Path $taskCacheRoot 'huggingface'
$env:TORCH_HOME = Join-Path $taskCacheRoot 'torch'
Set-Location -LiteralPath $taskStorageRoot
```

上述设置仅用于该专用会话，不修改系统级环境变量，不改写 `HOME` 或 `CODEX_HOME`。pnpm store、模型工具的额外缓存、浏览器 profile/下载等另行显式指向 F 盘，已运行的服务和浏览器不会自动继承新配置。F 盘不可用、空间不足或工具仍会写到盘外时，停止该项操作并记录阻碍，禁止回退到其他盘符或系统临时目录。

## 3. 当前程序默认值与历史路径

现有 OCR 源码的项目默认值仍为 `%LOCALAPPDATA%\OfflineOCR\Workspace`；校验记录、GPU 锁及外部审校凭据也使用 `%LOCALAPPDATA%\OfflineOCR` 下的目录。因此本机运行时必须在启动进程前把上述应用数据位置明确配置到 F 盘，并使用 `--data` 指定 F 盘工作区。**只传 `--data` 不足以满足全部文件只在 F 盘落盘的要求。** 临时路径兼容代码还有系统目录回退，运行前应确保 F 盘临时目录可用，并检查工具是否仍有盘外回退。

旧文档中的 C 盘桌面、D/E 盘包目录、旧运行根和跨盘验收结果属于历史记录，不代表当前允许写入。只读引用历史证据时保留其原始路径和哈希，不能把文本中的盘符改成 F 盘后宣称文件已迁移。续作时先建立 F 盘落点并记录新旧路径映射；已有盘外文件的搬迁或删除作为独立工作处理。

冻结任务包、脚本默认参数或宿主工具若仍包含旧路径，执行前必须调整其实际工作目录、输出及缓存配置，不能直接照抄旧命令。更换盘符的历史验收要求不授权在本机向其他盘写文件；本机路径测试使用 F 盘内不同目录及中文/空格路径。

本次为 Markdown 规则更新，未修改程序的默认路径、迁移既有文件或实现操作系统层面的写入拦截。后续工作须按本规范执行；项目协作入口见 [AGENTS.md](../AGENTS.md)。
