# 结构复核使用与恢复

2026-09-17 深度审计发现的 8 项程序缺陷已在源码修复，见[修复与回归](../audit/bugfixes-20260917/REPORT.md)。现有便携包未重新打包。结构面板和全文队列共用当前候选规则；工具、图像或修订变化后，失效建议不再列为待办，历史决定仍可查看。

1. 从本轮完整包的 `启动工作台.cmd` 启动，导入 PDF，选择页面或全文处理。默认“自动：原生优先、区域补识别”。区域失败时可重试；已完成的区域保留。
2. 采用要校对的结果，打开“结构复核”。尚无候选时，在“表格定位与人工绑定”生成候选。Paddle 是默认来源；TableFormer raw、RapidTable 及 local-v3 为实验选项，完整新包已带离线文件。
3. 点击“检查已有候选”，对照当前/候选行列、跨度、表头和原图。可展开局部图或定位到左侧原图。黄色待核对空值表示没有来源文字，不代表图中真实为空。
4. 接受合适建议，或保留当前、拒绝、暂缓；有文字丢失、跨格行框或表身份冲突的建议不能直接应用。需要手动修正时回到原表格编辑器；选中单元格可“切换表头”。结构接受后可使用原编辑器撤销/重做。
5. 左侧“文档复核”集中列出跨页任务，“下一处”导航。同表不同提供方和局部方案折叠为一个任务；结构变化后原检查失效，需要重新检查。队列为空只表示已生成的任务处理完。
6. 导出 Excel 读取当前修订并附来源；文字按字符串保存，前导零、负号、小数点不自动改写。采用结构建议后的 Excel 导出为 ZIP，含工作簿及结构来源 JSON。PDF 预检需要可靠定位并处理原生/OCR 重叠；结构建议正确不保证框正确，标题或改字可通过显式人工定位补齐。

原始候选和采用修订分开保存。选择其它图像版本、改变修订、重新生成候选后，旧待处理建议失效；不应重复套用截图中旧建议。网络响应中断时界面保留同一决策请求，可重试；相同请求不会重复创建修订。修改过请求内容则必须使用新请求编号。

旧工程中的几何产物可在“检查已有候选”时回收，但只接受原版本、原图哈希和已保存产物哈希均能核验的文件。缺失或损坏的旧产物需要重新运行提供方，不依据文件名猜测来源。模型、权重或依赖不符时会明确失败，不联网补下载。

工作区默认仍在 `%LOCALAPPDATA%\OfflineOCR\Workspace`。升级到 schema 10 前自动备份数据库，位置为工作区 `database-backups`。升级失败会回滚。需要回退到旧版本时，先退出新服务、另存当前整个工作区，再将升级前数据库备份连同原有项目文件恢复到单独工作区并使用旧包；不要让 schema 9 应用直接打开 schema 10 数据库。升级后新建修订不在旧备份中。

本版是公开材料实验交付；自动采用、真人省时结论及跨页表格合并均未开放。遇到空 OCR、漏表、复杂多级表头或跨格行框时继续人工核对，不以复核队列清空作为整文档准确证明。
