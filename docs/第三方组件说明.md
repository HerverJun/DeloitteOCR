# 第三方组件说明

交付包保留上游许可与版权文本，不把第三方代码或模型声明为本项目原创。精确安装版本见 `locks/*.json`，模型仓库和 revision 见 `locks/models.json`，各许可文件位置与哈希见 `licenses/index.json`。

| 组件 | 随包许可／来源 |
|---|---|
| CPython 3.12.10 | 各 `runtimes/*/LICENSE.txt`，官方 Windows embedded 发行包 |
| Paddle、PaddleOCR、PaddleX | 各运行环境的 distribution metadata、LICENSE / NOTICE；PaddleOCR 与 PaddleX Apache-2.0 |
| Paddle 模型与辅助模型 | 各模型目录 README 的上游声明；PaddleOCR-VL-1.6 另含 LICENSE |
| GLM-OCR 模型 | `models/GLM-OCR/README.md` 标注 MIT，保留固定 revision 模型卡 |
| GLM SDK、Transformers、PyTorch 等 | 各 `Lib/site-packages/*.dist-info` 及对应包内 LICENSE / NOTICE |
| HunyuanOCR-1.5 与 F16 派生文件 | `models/HunyuanOCR/LICENSE` 为原始模型许可；该模型原始目录一并保留，GGUF 的转换出处见其 source-manifest.json |
| llama.cpp b10894 | `licenses/llama.cpp-LICENSE`，来自对应 commit 源码；发行包中的 OpenMP 许可原位保留 |
| NVIDIA CUDA/cuDNN 等用户态库 | 来自 NVIDIA Windows wheels 或官方 llama.cpp CUDA 资产；各 wheel 的 dist-info 许可原位保留，不包含 NVIDIA 显卡驱动安装包 |
| Microsoft Visual C++ Runtime | 微软 Visual Studio Redist x64 可再分发 CRT；具体来源及哈希见 `config/msvc-source.json`；遵循微软相应再分发条款 |

`licenses/index.json` 是原始许可文件索引；`locks/*.json` 内的 License 字段来自上游包元数据，部分为 null，不能解释为无需遵守许可。构建脚本对 Paddle wheel 所作本地修改仅涉及版本及依赖元数据，另附修改清单和上下游哈希。
