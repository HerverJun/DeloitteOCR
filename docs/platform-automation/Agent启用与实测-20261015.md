## 停用与回退

如需停用，先按原启动器正常停止，确认没有活动 Agent 或原生任务；将登记中的 `agent_enabled` 改为 false 后再启动。启动器拒绝在有活动任务时直接停止，不能强杀绕过。

无需降级或恢复数据库来停用 Agent。启用前的数据库副本仅供故障恢复，恢复必须使用新的 F 盘 DATA，保留后续产生的记录，不覆盖正在使用的工作区。此前“Agent 默认关闭”的手册和历史交付记录以本次本机显式启用说明为补充。
