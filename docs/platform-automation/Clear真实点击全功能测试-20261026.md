## 修复及复测

1. OCR 可选 Pro 缺失时，注册解析异常绕开自动后备引擎：将解析放入既有预推理回退边界；原失败任务真实重试成功。显式缺失引擎仍失败，21 项队列回归通过。
2. 纯文字 PDF 不必要调用 OCR，冷启动失败导致部分完成：用精确源 SHA、完整页图和保守内容流证据确认纯文字覆盖；图片/混合/未知页仍走原覆盖检查。最终复查又发现已知操作符参数损坏（如 `1 2 Tj`）未拒绝，已补数量、PDF值类型、有限数值及文字/图形状态平衡校验。45 项针对性回归和实际固定解析 worker 通过，同一正常 GUI 任务重试成功。
3. 资料集合尚未核实时发送按钮未禁用：补齐 asset_set 条件；原资料文案改为所选资料；完成任务不再提示停止 Agent。7 项行为回归通过；GUI 已核实集合文案、已完成任务提示与设置返回原会话均通过。
4. 能力列表无本机 GPU 回执仍全库重哈希：展示资源存在状态，实际推理准入继续完整验证。冷进程实测由超过 30 秒降至 0.891 秒，41 项回归通过；GPU 资格来自本轮真实运行，未复制或伪造旧回执。
5. 跨工具结果参数泄漏及错误类型详情：跨页面清理私有参数，任务及固定快照核对工具类型。39 个相关场景通过；GUI AIGC→音频链接仅保留项目，手工错类型链接显示明确提示并提供正确工具入口，通过。
6. 自定义比较主题硬编码项目名：按主题和字段提取原文对象标识，阶段系统提示纳入缓存身份；55 项核心及语料回归通过；GUI 新修订按采购单号对齐成功，没有强制把含糊金额判为相同或差异。
7. 训练提交跳转隐藏新任务：保留真实 job_id，选中新训练、显示全部执行记录并展开日志；类型检查通过；GUI 新建训练与分类实际复测通过。旧分类构建曾未展开详情，最终源码构建已正常，不额外猜测修改推理逻辑。

初次「上传无反馈」未证实为业务保护拦截；源码没有对应 guard，未凭猜测修改上传逻辑。最后在同一已完成任务上下文、不手动接管，使用语义按钮上传「采购核对说明.txt」成功，证实上传并不受接管限制。
