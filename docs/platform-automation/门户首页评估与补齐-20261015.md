# Clear 门户首页评估与补齐

日期：2026-10-15。状态：门户首页已实现并更新到本机 8910 前端预览。入口为 <http://127.0.0.1:8910/>；正式 8879 版本未切换。

## 评估结论

缺口来自入口和信息架构，而不只是配色。原 `/` 直接挂载 `AgentWorkbench`，`/agent` 又重定向回 `/`，品牌按钮也返回 AI 页面。用户进入产品后无法先了解工具、项目与成果入口；首页还会直接加载 Agent 状态和对话依赖。单独美化工具目录无法解决这一问题。

此次补齐以导航与继续工作为主：默认先展示门户，AI 对话保留为独立工作区。页面数据只使用现有工作空间列表，没有添加虚构业务统计、进度或准确率。

## 已完成内容

- 首屏以资料到成果的四步流程说明工作方式，提供手动工具和智能审计入口。
- 中部展示六类工具、印章识别与深度取证两个专项扩展，并提供项目管理和 AI 工作台入口。
- 下方展示实际已有审计项目，提供资料库、任务中心、成果中心和使用指南。
- 左侧新增“平台首页”，原有智能审计、审计项目、手动工具标签保留；品牌按钮返回门户。
- 项目列表具备加载、空状态、读取失败和重试；项目读取失败仍可使用工具入口。进入门户不调用 Agent 或推理接口，不启动任务。
- 延续 Clear 浅色与绿色品牌、官方 Ant Design 图标、本地中文字体；五种宽度下检查布局。

## 路由与上下文

| 地址或动作 | 当前行为 |
|---|---|
| `/` | 门户首页 |
| `/?workspace=...` | 带当前项目的门户 |
| `/agent` | 独立 AI 审计工作台 |
| 旧 `/?session=...` 或 `/?continue=...` | 使用 replace 跳转 `/agent`，原查询参数和锚点保持 |
| 品牌按钮 / 平台首页导航 | 回到门户，保留项目等上下文，清除 AI 会话与续办参数，避免重新进入对话 |
| AI → 工具 / 项目导航 | AI session 转为 task_return，保留关联审计任务，不重放 continue |
| 工具 → AI 导航 | task_return 恢复成 AI session；原生数据 session 不得充当 AI session |
| 项目开始审计、任务续开、人工结果带回、发现返回对话 | 显式进入 `/agent` |
| 原生工具“返回工具选择” | 回到 `/apps` |

`navigationHref` 集中处理主导航的上下文。现有工具、任务与资料路由保留。新增首页和侧栏共用六工具导航定义，工具目录仍保留原有启动校验与服务状态实现。
