# Clear 全平台 GUI 升级实施与验收

2026-10-19。状态：**已完成 Clear 0.15.0 GUI candidate-002 的实现、验收与候选交付。**

试用入口：<http://127.0.0.1:8970/>，Agent：<http://127.0.0.1:8970/agent>。目前由固定候选启动，使用本轮隔离 DATA。正式 8879 入口仍登记 Clear 0.14.0 candidate-006；本轮没有切换正式发行或改写正式业务 DATA。

## 实现结果

- 公共导航收敛为工作首页、Agent、项目、工具；工具选择器集中专业入口，项目切换保留一个主要控件。资料、任务和成果有稳定的辅助入口。
- 首页改为新任务、继续工作、项目与常用工具。选定项目后读取现有概况接口；未选项目时展示按账号隔离的最近访问。浏览首页不启动 Agent、模型或专业服务，也不加载 Agent 主模块。
- Agent 使用通用工作文案，覆盖问答、文件、台账与专业分析；默认收起详情、空计划和无关专业授权。运行诊断、完整来源版本及哈希保留在展开项。支持 Enter 发送、Shift+Enter 换行及输入法组合事件保护。
- 修复空会话自动滚到底部造成欢迎标题裁切的问题，保留阅读历史时的滚动位置和流式更新逻辑。手动接管改为稳定入口，原有暂停、继续、取消和待核实控制契约保留。
- Data 按输入与清洗、比对设置、结果与导出切换，切换时保留控件状态。项目增加名称搜索；成果提供本页名称／文件搜索和类型筛选，原生工具内输出移入展开区，减少重复呈现。任务中心把维护用的原生任务关联与内部身份放入详情。
- OCR、分类、门户统一为 Clear UI 1.3.0，使用相同颜色 token、本地中文字体、控件尺寸和焦点规范；分别适配原有 Fluent UI、Ant Design 5 和 Ant Design 6。
- OCR 保留原件对照、文字／表格编辑、自动保存、恢复、队列和导出。分类默认进入预测与复核，预选已有模型；训练与模型管理独立分组，执行历史默认筛选分类任务并可展开全部记录。
- 原生 OCR／分类保留独立工作区。通过现有已核实票据附加受限的返回上下文，校验项目和实例后返回原 Agent 会话；刷新仍保留返回关系。没有放宽现有票据或平台返回地址的校验。
- 修复分类复核窗口在保存后立即关闭、随后被异步“下一项”重新打开的问题；关闭和重新打开窗口会使旧导航意图失效，处置请求及其幂等身份继续保留。
- 取证与专项分析继承统一规范，已有结果时可收起分析设置；原图、热图、播放／文本结果及人工判断继续使用原服务和真实状态。

业务 HTTP API、DSH 决策循环和数据格式沿用 0.14.0。UI 的最近访问、布局偏好和返回上下文只用于导航，不作为任务执行事实。内核继续为 **DSH 0.2.1-alpha.4**。

  'F:\OCR\output\gui-experience-upgrade-20261019\delivery\Clear-0.15.0-gui-candidate-002\launch.py' `
