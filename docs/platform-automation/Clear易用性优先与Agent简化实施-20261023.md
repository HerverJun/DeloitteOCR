# Clear 易用性优先与 Agent 简化实施

日期：2026-10-23（香港时间）。用户已授权实施。本文是本轮唯一简短实施计划，完成记录由最终受测行为与实际交付补充；规划、源码修改、候选验收及正式发布分别说明，不提前宣称完成。

- 本轮从已验收 **0.17.1、提交 e5ca875** 建立独立 **0.20.0 易用性候选**。0.18.0文档主题对比、0.19.0 AIGC由其它线程负责，本轮不合入其功能，也不把它们的验收当本轮证据。
- 工作根为 `F:\OCR\output\agent-usability-upgrade-20261023`，运行前加载其中 `environment.ps1`。源码、隔离DATA、临时/缓存、浏览器产物和候选只写F盘；正式资料与历史结果保留。

## 先确定产品标准

用户用正常表达完成常见目标并拿到可用结果，是本轮首要标准。减少重复提问、点击、模型往返、等待和内部术语；功能数量与状态数量不能替代使用效果。

普通问答、文件处理和专业工具使用无需先建审计档案、填计划或完成正式发布确认。系统自行完成固定的准备、等待、读取和保存；确实影响结果的歧义再询问用户。正式复核与署名按实际目标进入，不替用户署名。

原件、编号与金额、资料范围、权限、幂等、未知业务写入核实及用户主动停止保持。成功须有真实结果，部分失败不遮住已完成成果。来源、版本、回执和诊断继续保存，默认界面突出结果与下一步，技术细节按需查看。

## 验证范围

以少量覆盖本次改动的常见任务为主：普通问答、文件处理与实际下载、受影响专业服务、追加/暂停/故障后续作和旧结果读取。具体选择以最终改动为准；对范围、金融值、来源或未知写入的改动增加对应反例。涉及界面行为时检查真实入口与文件使用，而不是只看构建成功。

观察任务是否完成、首次有用结果、总耗时、模型请求及用户被迫干预次数；这些用于定位浪费，不是达到数字就截断任务的上限。只有需要证明提速或排查波动时增加重复次数，不新建大规模benchmark，不重跑无关设备、中央部署或历史长测。

工程provider、真实模型、浏览器和原生业务证据分别说明。已有未受影响的证据可标明版本与范围后引用；已修复的10月18/19问题没有新复现就不重复开发。未覆盖的业务精度、目标设备和正式部署范围如实记录。
