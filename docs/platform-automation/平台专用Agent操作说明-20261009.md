# 平台专用 Agent 操作说明

更新：2026-10-09。适用范围：本轮隔离工程候选的批量屏拍、现有 OCR 成果核对和已发布模型分类流程。

正式运行版本仍为 v0.9.3。本轮已验证业务说明修改、复核版本和当前 ZIP 的工程流程，完整质量、240/24 大批次及最终候选资格仍在验收。下列操作说明不表示候选已经可正式采用；当前识别成果继续按界面显示的待核范围复核。

## 批量屏拍转 Excel

在对应项目选择图片资料，向 Agent 明确目标，例如：

> 将这批屏拍图片转为 Excel。每张图片一个工作簿，同图多表分 sheet，整批 ZIP；保留标题、单位和表注，数值按原文文本保存。

Agent 使用项目内固定的资料集合和后台批次。先看批次进度、已完成文件数、失败原因和待复核范围；耗时较长时继续使用原批次。首个候选出现仅说明已经有提取结果，内容正确性仍以复核及验收为准。

平台端打开“核对原图与结果”；原生端从“拍屏表格批量转 Excel”进入“最近表格批次”，再打开图片。先核对表格行列、合并跨度、金额、编号和正负号，再核对业务说明。可靠格位会指向原图位置；没有可靠格位的异常仍需按表或整图检查。

## 修改表格和业务说明

复核界面显示当前值及可用的另一识别原文。业务说明可使用“选用辅助识别原文”或对应的主识别选值按钮，也可直接修改“业务说明…复核值”。主识别和辅助识别不同的内容保留来源，选择原文先填入待保存的复核草稿，保存后才写入当前修订。

表格单元格和业务说明可在同次保存中提交。使用“保留当前结果”保存尚未确认的修改，图片继续待复核；核对完成后使用“保存并确认本图”。原始识别保留，修改记录写入当前修订。

两端标签对应如下：

| 操作 | 平台端 | 原生端 |
|---|---|---|
| 保存草稿，继续待核 | 保留当前结果 | 保留当前内容，仍待核对 |
| 保存并确认本图 | 保存并确认本图 | 保存并标记核对完成 |
| 下载待核提取结果 | 包含待复核文件 | 下载时包含待核对结果 |

重新打开复核时，以最新读取的原图、当前选定候选、修订和确认状态为准。若界面提示这些内容已变化，刷新后重新核对并保存。后续修改或切换候选会重新计算待核状态，之前的确认不自动继承到新内容。

局部候选只有在当前原图、当前结果及可靠疑点位置均可绑定时才能提交。它展示独立文字与裁剪证据；不会自行覆盖当前值。用户修改、重新确认或换候选后，旧局部候选可以保留为历史建议，但不能继续作为当前来源。

## 下载当前成果

确认下载范围后使用“下载逐图 Excel ZIP”。“包含待复核文件”允许下载尚待检查的提取结果；待核标记和失败原因仍随成果保留。每个可交付输入对应一本 XLSX，同图多表分别在工作表中。

平台端“下载 Excel ZIP”对应已经生成的当前成果。编辑、换候选、重新确认或批次继续处理后，原有下载会显示为“下载历史 Excel ZIP”；即使文件数相同，也应重新导出当前 ZIP。历史文件保留原版本，不会被悄悄改写。原生端直接下载当前范围，当前没有对应的历史成果链接标签。

部分下载只覆盖当时已经可交付的范围。失败、空表和预算终止的输入仍保留在清单中。继续处理后再次查看当前范围和待核状态，再下载新的 ZIP。

## 暂停、续作与定向处理

需要中途停下时使用原批次的暂停操作；继续处理使用同一批次的续作入口。成功且原图、结果未变化的项应继续复用，失败或未完成项保持原原因与成本记录。

重试失败或对选定图片提高精度时，明确选择范围。技术故障兜底与提高内容精度分别记录；慢处理不会延续已经过期的原图或人工确认。加载或识别连续同原因失败时，保留现场并受控停止，不应通过反复新建同一整批来延长原预算。

重复点击或对提交结果不确定时，先查看原操作和批次回执。原任务的身份、已花成本及截止时间保留；新的独立试验需要明确的新身份。

## 核对已有 OCR 成果

向 Agent 指明已有 OCR 成果、对照资料以及核验规则，例如：

> 用这份当前 OCR 成果与已选择的对照资料核对编号和金额。金额单位为元，按项目规则计算差异，保存可追溯的审计证据并交付核对成果。

Agent 应读取当前工作表、真实字段和资料范围，再使用结果衔接、数据核对和审计工具。当前衔接不支持的合并语义、缺失格位或不完整结构需先处理，不应把猜测的表格当作已读取的下游输入。正式人工签署由平台的人工确认入口完成。

## 使用已发布分类模型

明确资料范围和已有发布模型，要求 Agent 使用该模型完成分类，并保留输入、模型版本、实际预测和成果来源。已发布模型预测与新增训练是不同任务；分类目标不会自行扩展成训练或增加未授权资料。

## 采用与回退

本轮候选的采用范围须以最终冻结源码对应的质量、效率、界面、兼容、包装和冷恢复报告为准。当前已通过的局部界面或单图推理不能代替完整候选资格；模拟数据成绩也不能换算真实手机屏拍准确率。

正式采用前分别停止平台与原生应用，使用对应的数据备份入口保存平台及原生 OCR 根；平台备份默认不包含另一个原生根。备份、恢复、截图和候选包都放在本机 F 盘的登记目录中。

恢复旧程序前核实它是否支持数据实际使用的功能和修订格式。旧读取器拒绝新业务说明修改或局部候选数据时，应使用对应的恢复备份和匹配读取器；不得删除修改历史或绕过兼容检查。候选资格通过之前，正式入口继续保留 v0.9.3。
