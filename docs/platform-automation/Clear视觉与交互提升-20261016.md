## 实现

保留 `#527a17` 主色、`#86bc25` 强调色、`#f6f8f7` 工作区、白色面板与本地 Clear Sans 字体。沿用 React、Ant Design 与 CSS，没有新增前端依赖。

- 宽屏使用 232px 导航、会话区和 300px 任务面板；正文最大宽度 840px。1280px 以下任务详情使用抽屉，991px 以下导航使用抽屉，680px 以下单列及主要控件 44px 触控区域。任务面板收起偏好保存在浏览器。
- 任务名成为主标题，模型为次级标识。独立输入容器整合资料、输入和发送；阶段与上下文估算位于紧凑状态带，真实作业可以直接打开。暂停／继续直接可达，两种停止、接管和整理上下文在辅助菜单中保留各自语义。
- 任务面板汇总现有任务和 SSE 投影，展示目标、计划轨迹、作业、阻碍、交付检查及成果。分段核验与最终交付区分，缺失状态或容量不当作已确认。
- 连续成功工具折为摘要，执行、等待、未执行和待核实项保持突出；用户展开后继续保留。调用身份、参数和完整用量留在诊断视图，来源与下载可回查。
- 悬停／按压 120ms，工具折叠 180ms，面板和实时新消息 240ms。使用 CSS、原生 Web Animations API 与逐帧滚动协调；历史、会话切换及 token 更新不重播入场。手动阅读中保留锚点和未读计数，减少动效设置直接切换。
- 门户保留原入口优先级与双栏结构，证据路径改为有序四步轨迹；修正微小文字、对齐、图标、导航反馈及留白。长问题和选项在手机完整换行，紧凑回答按钮保持单行。

公共 API、SSE、权限、操作身份与运行策略未更改。候选的 Python 业务代码、契约、Harness、Node、原生应用和依赖与 0.12.0 封存版本逐文件哈希相同。子工具内部页面未重做。
