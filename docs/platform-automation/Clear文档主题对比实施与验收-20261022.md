## 2. 主要实现

### 解析与统一文档

- PDF 逐页渲染；PPTX 经隔离 LibreOffice 静态导出后逐页渲染；图片组保留用户顺序。
- 本地模式显式选择 PaddleOCR-VL 完整流水线或 MinerU Pro。新增常驻批次处理，批次上限 20 页；实际两页验证确认第二页复用模型，GPU 资源按任务所有权管理。
- 多模态模式每次只发送一张当前页图片及固定指令，不带前页结果或累计对话。校验图片字节、尺寸、上下文与输出预算，检查截断，已知非法结构最多补试一次；未知结果记录后停止自动重发。
- 统一为 `clear.document`，保留页序、块类型、表格、原文及来源。VLM 坐标标记为模型估计；缺失或不可靠坐标使用页级引用。
- PPTX 保留 slide 编号、隐藏标记、页映射及坐标变换。原生文字候选用于诊断；只有与可见 OCR 内容及区域匹配时确认，避免把页外或遮挡内容当作正文。备注不参与，隐藏页包含并标记。

### 主题、供应商与比较

- 保存版本化 `LayoutParseConfig`、`ComparisonProfile` 和供应商配置。支持 OpenAI Chat Completions 兼容协议与 Anthropic Messages，自定义端点、模型、密钥和能力参数。
- 密钥通过现有本机 DPAPI 密钥库保存，页面与任务快照不回显明文。连接升级保留旧版本；空 Key 沿用现有密钥。
- 主题可由自然语言生成字段建议，也可直接编辑。字段支持文字、日期、数字、百分比、容差及别名；内置项目进度模板。
- 分块抽取后先验证原文引用，再按项目 / 工作项对齐。数值、日期及百分比由代码归一，语义判断由模型完成。无效引用、日期口径不一致、未对齐或覆盖缺失时降为信息不足。
- 结果固定五类：一致、存在差异、仅 A 提及、仅 B 提及、信息不足。

### 任务、修订与固定交付

- 增加工作区作用域的 `/comparisons` API，包含配置、连接、探测、任务创建、状态、取消 / 恢复、页面回看、单页重跑、页面校对、仅重跑比较和文件下载。
- 相同请求编号及请求体复用原任务；材料版本、配置版本和模型连接版本在创建时固定。逐页检查点保存，调用账本区分成功、失败与未知结果。
- 页面重跑和人工修订产生新修订；`recompare` 可更换字段 / 模型并复用解析结果。历史报告保留且只读，下载和证据回看带具体修订号。
- 比较阶段失败仍可下载已解析的左右 JSON / Markdown。报告固定为本地七章节 HTML 模板，所有输入及模型内容转义，禁止模型生成页面样式与脚本。
- 输出 `report.html`、`comparison.json`、`left/right.json`、`left/right.md` 和 `manifest.json`，接入成果中心。直接下载与成果中心归档采用相同 UTF-8 字节。

## 5. 审查中修复的关键问题

- 补齐成果中心比较文件的下载分派，确保目录、详情和下载均识别 `document_comparison`。
- 修复 Windows 文本写入换行转换，使 HTML / Markdown 的直接下载、归档与 manifest 摘要使用一致字节。
- 对比较抽取不完整及语义失败标记部分完成；成功 OCR 不再掩盖比较阶段缺失。
- 显式重新比较使用独立重试身份，允许用户确认后重试旧未知比较调用，同时保留成功调用复用；普通恢复不自动重复未知调用。
- 表格校对由服务端保留原块身份和单元格来源，并从修订单元格重建正文。前端将表格正文设为只读预览，避免旧表格结构覆盖文字编辑。
- 历史页面和文件下载固定修订号；历史版本禁用修改；任务历史使用服务端分页，旧任务仍能识别当前最新修订。
- 使用受锁保护的 SQLite 长连接与 WAL，减少 F 盘高频轮询打开 / 关闭数据库的抖动。
