# Clear 前端工作台改版与预览

日期：2026-10-15。状态：已完成门户框架与手动工具目录改版，并补齐独立门户首页。当前预览首页为 <http://127.0.0.1:8910/>，工具目录为 <http://127.0.0.1:8910/apps>；AI 对话位于 `/agent`。正式 `release/Clear/current.json` 及 8879 发行入口未切换。最新路由、兼容及本轮验证以[门户首页评估与补齐](门户首页评估与补齐-20261015.md)为准；下方 160 项全套记录对应最初工具目录改版阶段。

## 参考与设计判断

本轮将现有应用视为审计人员使用的专业工作台。继续使用 React 19、Ant Design 6、React Router 和 TanStack Query；没有移植其他项目的后端或改用新的应用框架。

参考来源于 2026-10-15 实际读取的公开资料：

- [Ant Design Pro](https://github.com/ant-design/ant-design-pro)：企业工作台的导航、内容容器和操作层级。
- [Ant Design 布局规范](https://ant.design/docs/spec/layout)：界面区域、栅格、间距和响应式布局。
- [Supabase Studio](https://github.com/supabase/supabase/tree/master/apps/studio)：项目上下文与工具导航的组织方式。

以上是交互与布局参考，未复制其页面源码。本项目原有 Ant Design 为实际组件基础，新增加的 `@ant-design/icons` 6.3.4 使用官方图标；包版本与锁文件均已登记。该包原已存在于本机离线依赖中，本轮只建立 F→F 依赖引用，未下载新的运行资产。

## 改版前的问题

原界面深色侧栏占比较重，导航项少且工具入口集中在主区；卡片标题、用途、说明、状态与声明的视觉差异较弱。工具目录缺少搜索与类型筛选，印章和深度取证扩展入口不直观。字体依赖系统回退，中文呈现不一致。原品牌绿色、平台标识、三项主导航、已有路由及任务启动逻辑适合继续沿用。

## 实际改动

1. 浅色顶栏与侧栏、项目上下文、六个工具快捷入口、统一留白和文字层级。
2. 手动目录支持按文档、数据、图像、音频筛选，支持名称和用途关键词搜索；`Ctrl/Cmd+K` 聚焦搜索，无匹配结果可清除筛选恢复。
3. 六个工具保持既有运行状态、文件校验、启动请求身份、弹窗与项目续开逻辑；卡片统一图标、状态、说明与操作位置。
4. 单独展示印章识别、CAT-Net 深度图像取证两个专项扩展入口。筛选不会修改项目参数，快捷入口继续携带查询参数和锚点。
5. 引入随包加载的中文 UI 字体。来自项目已有 OFL 授权 Noto Sans SC，按现有界面字符制作 WOFF2 子集，补齐门户后为 195,656 bytes；保留授权文本与再生成脚本，用户资料中未包含的字符继续使用系统字体回退。运行时不请求在线字体或图标。
6. 保留错误重试、加载、工具声明、键盘焦点和减少动画偏好；窄屏侧栏可展开并在导航后关闭。

当前范围包括门户首页、公共框架与工具目录。OCR、分类原生应用的编辑工作台和六个专业工具的内部流程仍使用既有实现。预览连接现有 8879 本机后端，读取当前工作区；浏览器验收只读，不上传文件、不执行模型、不创建或更改业务记录。用户在预览中主动执行操作仍会交给现有后端处理。
