## 交互与主线

左上角品牌区包含标志、产品名称和说明文字，点击后在当前标签页进入审计平台首页 `/`，保留已选择的工作空间。链接显示“返回审计平台首页”提示，使用标准链接语义支持 Tab、Enter 和浏览器返回。数据工作台使用门户已有品牌入口；OCR 和分类补齐同样入口。现有项目级返回链接继续用于回到对应工具流程。

## 首页关联

从平台通用应用卡片打开原生工具时，平台在完成实例和会话核实后交接首页地址及原生实例身份；地址仅进入浏览器片段，原生页消费后移除。项目级打开根据已核实的项目返回地址得到平台首页。原生独立启动时不猜测平台端口。

首页关联仅包含本机 `127.0.0.1`、有效 HTTP 端口、根路径和可选工作空间，不包含令牌、票据或项目操作权限。当前标签页刷新时先核实原生实例；过期、非法或无法核实的缓存不展示链接。沿用原有会话及票据校验。
