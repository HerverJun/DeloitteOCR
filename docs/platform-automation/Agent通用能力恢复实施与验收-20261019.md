本记录接续[调研结论与升级计划](Agent通用能力恢复与审计增强调研升级计划-20261019.md)。原调研是对正式 0.13.0 candidate-018 的历史判断；本记录区分后续实现和实际验收，失败记录不覆盖。

## 已落实的产品取舍

保留 DSH 主循环，恢复文件、搜索、PowerShell、Python、后台作业、技能脚本、Web fetch、MCP、按需子助手及主控图片输入。新普通任务用自然文字结束；旧会话保留原回答和发布契约。脚本和文件输出使用专用 F 盘目录，实际文件自动固定版本并提供下载。

专业能力复用已有应用服务。常规文字提取、批量清洗和 OCR 任务内选参有组合入口，原生等待、读取和导出由服务执行。一次工具搜索即可加载定义；不再要求普通任务先建立正式审计档案、计划或发布流程。正式人工复核仍需真实用户对固定版本确认，拒绝后保留草稿。

工具选择以完成用户目标为准。自然提出“提取图片、核对台账”时，真实任务通过 OCR 和实际 CSV 读取，在三次请求中完成差额 18.55、币种缺失、编号缺少对应资料等说明。额外强制全部经 Data 的实验出现三十余轮长链后已受控停止，保留记录，不计成功。本轮不把这条额外工具链作为普通核对任务的前置条件；正式要求 Data 工作流的独立场景仍需单独验证。

## 本轮发现并修复的复杂化来源

- 普通文字被旧统一交付条件反复要求继续，已经由新契约的自然收尾替代。
- 取消的宿主误入空闲缓存、终态交接时续作被拒绝，以及空闲上下文整理争用会话写句柄，均已修复并回归。
- 原生工具的预览缺少标准引用数组，投影时反复包装导致越压越大；真实故障及专门收敛回归保留。
- 重复注入的会话和操作详情已精简为执行事实；真实记录仍可回查。摘要预算随压缩片段大小调整。
- 读取两条 OCR 审计证据时，原始引擎载荷约 11 万字符进入上下文。聊天证据视图改为固定原文、版本和来源，完整载荷继续保存在原记录；历史大快照可做有标识的预览投影。
- 专业成果返回实际下载地址，减少模型为拼接地址而重复查询目录和历史。
- 已结束会话的产品查询使用会话范围校验，修复底稿被错误标记过期。旧底稿重新查询恢复为 `draft`，十份原文件逐字节哈希不变。
- 通用请求仅发送最新运行快照，完整历史快照继续保存在原事件中。定向检查同时证明用户模拟相同标题的正文仍保留、文件工具调用和旧收尾契约可用。此前五轮整理的底稿轨迹保留，不重标为修复后成绩。
- 固定成果读取器增加 UTF-8 Markdown 和 HTML 原文读取，继续校验版本、范围、全文编码及原文件哈希；HTML 只读源文字。21 项成果读取检查通过，含二进制、NUL、非 UTF-8、错范围和错哈希反例。
- 原底稿链要求模型逐项传递证据与发现 ID。新 `audit_create_workpaper` 在现有服务内完成绑定、保存、导出和正文读回，不增加工作流引擎。所有来源先核实，发现固定为 Agent 草稿；导出中断返回已有发现及继续缺失步骤的引用，同一操作恢复不增加重复发现版本。3项新旧接口及故障/范围检查通过。
