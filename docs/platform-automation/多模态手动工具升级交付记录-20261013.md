正式入口已切换为 **0.10.0 多模态手动工具 CPU 版**，访问 http://127.0.0.1:8879/apps 。原工作区继续使用，旧版及升级前冷备份保留。**本次完成工程版本发布，整体升级尚未登记完成。** 用户目前没有业务验收资料，A4000/A6000 尚未现场验证；新增 GPU 路线也保持关闭。

## 交付内容

保留 ClearOCR、ClearClassification、ClearData、ClearForensics 四入口，新增人脸、音频工作台；印章与 CAT-Net 分别扩展原 OCR 和取证入口。四类流程均接通原件导入、真实模型分析、原件对照、人工说明/校正、保存重开、成果归集与导出。印章核准字段可转 Data；成果可作为既有审计调查事项的直接证据引用，Agent 关闭时仍可用。

模型为 YuNet 2023mar、SFace 2021dec、CAT-Net v2、Paraformer 中文时间戳、FSMN-VAD、ct-punc、CAM++，以及官方 PP-DocLayout-L、PP-OCRv4_server_seal_det、PP-OCRv4_server_rec。固定版本、全部模型/字典/配置哈希、许可证与归属说明在包内 `model-inventory.json` 及 `program/models/multimodal`。

CAT-Net 源码的 89 个文件匹配官方提交 `331b8059c3f55efec1d9075de79dd153413f2061`；代码 Apache-2.0、权重 CC-BY-4.0，保留作者、论文和许可全文。音频四组资源已核对官方固定 revisions、文件大小与 LFS SHA；ct-punc 的最终权重为 1,125,507,622 字节，SHA256 `7176cae922a872e130e6b88aef9a1153581711baf79c9124c7c95be383cd6f81`。FunASR 软件 MIT 与模型 Apache-2.0 分别登记。

## 共用工程与兼容

- `SourceLocator` 增加媒体片段时间与声道；旧来源序列化和指纹保持兼容。图像和印章保留原页坐标，音频保留采样、声道和时间间隔映射。
- SQLite 增量保存任务、项目参考库和人工修订。模型结果与人工修订分开；任务排队、取消、失败重试、重启待核实及独立推理进程已接通。
- 记录权重/算法/运行时哈希、参数、设备与修订版本。人脸 embedding 不进入浏览器或导出。原件和成果读取/导出进行哈希核验。
- 修复 Windows 中文路径的人脸模型加载、印章模型路径和 JPEG DCT 临时处理；修复 Paddle oneDNN 不兼容与 Windows 进度文件替换冲突。临时、缓存与应用数据均显式指向 F 盘。
- 旧 reader 拒绝已有多模态记录，即使能力 marker 丢失也会检查数据库；启动新程序不会仅因声明新能力而把空工作区标记为已写入新格式。
