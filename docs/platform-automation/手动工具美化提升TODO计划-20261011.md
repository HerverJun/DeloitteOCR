## 1. 目标与范围

完成后应达到：打开手动工具目录即可理解四个工具的用途和真实状态；进入工具后，当前项目/文件、主要操作、结果和来源清楚；在常见办公屏幕上，把更多空间留给表格、图片和编辑内容；三套前端遵守同一套 Clear 视觉规范；美化资源完整进入内网候选包。

| 范围 | 本轮工作 |
|---|---|
| 平台外壳与手动目录 | 页头、项目上下文、侧栏、工具入口、最近工作、状态和声明 |
| ClearData | 会话/修订、导入预览、清洗、比对配置、差异结果、来源与导出 |
| ClearForensics | 图片选择、工具配置、原图/热图、任务、人工审阅、报告 |
| ClearClassify | 项目概览、图像与标注、训练/模型页面、分类任务与复核 |
| ClearOCR | 文件与文档导航、识别栏、原图与结果、校对编辑、队列与导出 |
| 公共交互 | 表单、表格、消息/弹层、加载/空/错误状态、键盘、响应式 |
| 交付 | 三前端构建、静态绑定、资源清单、断网检查、候选报告与回退方案 |

自动优化、Agent 调度与提示、模型选型/下载、算法和数据库改造不纳入本轮。门户共享主题若影响智能审计页，仅检查其显示与导航回归。OCR 沿用 Fluent UI 9，分类沿用 AntD 5，门户沿用 AntD 6；本轮不做组件库迁移或大版本升级。

## 2. 实施原则与视觉规格

### 2.1 已有基础与新增重点

已有 Clear UI v1.1.0、三套主题映射、加载/错误/空状态和专业操作流程。实施时优先修正现有样式和组件参数；仅对重复且确有复用价值的结构提取小组件，不新建跨仓库运行时组件平台。

新增重点是两档密度、统一工作台操作区、目录首屏压缩、Data 操作层级、图片与复核界面的空间分配，以及原生静态资源的交付核验。实施前目录的 1440×960 截图确认四张卡片占据绝大部分首屏；MP02 已完成其他模块采样，本轮结果见各项验收记录，不以源码推测代替画面证据。

### 2.2 实施起点

以下沿用既有规范并补充密度规则。MP05—MP10 用中文实际页面核对后固定数值；同一语义跨前端一致，专业编辑区允许必要差异。

| 项目 | 目标规范 |
|---|---|
| 配色 | 石墨导航 #161C1F、工作区 #F5F7F8、面板 #FFFFFF、边框 #E1E6E9；品牌绿 #86BC25、操作绿 #527A17、选中底 #EFF5E7 |
| 语义颜色 | 信息、成功、警告、错误沿用现有 Clear tokens；状态必须有文字，不能只靠颜色 |
| 字体 | 本地 Segoe UI / Microsoft YaHei 等系统字体；正文/表单 14px，辅助 13px，页面标题 26–28px，区域标题 18px；低频元数据才允许 12px |
| 数字 | 金额、数量、耗时启用 tabular-nums；数值右对齐；不通过显示格式改变原值和导出值 |
| 普通密度 | 页面内边距约 24px、面板约 20px、控件高 36px、主操作 40px，适合目录和概览 |
| 工作台密度 | 页面内边距约 16px、面板约 12–16px、工具栏间距 8px；表格局部 small/compact，编辑文字保持可读 |
| 空间 | 4/8px 间距尺度；内容平面优先，减少连续嵌套卡片和重复标题；图片/表格/编辑器按可用空间伸展 |
| 圆角与阴影 | 控件约 8px、面板约 12px；阴影主要用于浮层，普通内容用背景和轻边框区分 |
| 交互 | 每个操作区域明确一个主动作；提交中有反馈、禁用有原因；成功反馈不挤占主要工作区 |
| 焦点与对比度 | 正文目标至少 4.5:1，焦点和必要图形至少 3:1；键盘焦点可见、弹层可关闭并恢复焦点 |
| 动效 | 沿用约 160–200ms 的短反馈，支持减少动效；不引入滚动装饰、背景视频或持续干扰编辑的动画 |
| 窄屏 | 通用页面可换行/折叠；关键触控目标至少 44px；宽表格在容器内横向滚动，不强行缩成不可读表格 |

## 7. 视口与状态验收矩阵

### 7.1 视口

| 场景 | 必查内容 | 合格标准 |
|---|---|---|
| 1366×768 / 100% | 目录及四工具核心操作页 | 主操作清楚且可达；工作区有实质内容；工具栏不过度占高 |
| 1440×960 / 100% | 目录与 Data 样板前后对照 | 同一内容和视口比较；目录有最近工作时至少一条完整记录进首屏 |
| 1920×1080 / 100% | 四工具正常工作状态 | 表格/图片/编辑区有效利用宽度；正文不无约束拉长 |
| 1366×768 / 150% 与 200% | 导航、主操作、表单、弹层 | 可通过换行/折叠/受控滚动继续操作，不裁掉关键按钮 |
| 1024×768 | 原图/结果、双表、复核弹层 | 不发生重叠和不可达工具；专业面板按空间调整 |
| 390×844 | 目录、选择/表单、任务和结果入口 | 通用页面不横向溢出；专业大表/图像允许容器滚动，操作仍可达 |
| 中文长内容 | 长项目名、文件名、列名、类别和说明 | 合理换行/截断并可查看完整值，动作不被挤掉 |

每页至少覆盖桌面常用视口；高缩放/窄屏重点覆盖本轮变化较大的区域，不要求所有状态与全部视口做无意义的笛卡尔积截图。

### 7.2 状态与交互

| 类别 | 覆盖状态/动作 | 关键判断 |
|---|---|---|
| 入口 | 未选项目、首次使用、已有工作、失效记录、返回平台 | 入口/解释清楚，项目和任务上下文正确 |
| 服务与执行 | 待启动、启动中、加载、排队、运行、取消、成功 | 展示来自真实状态；无未知进度伪百分比 |
| 异常 | 导入/接口失败、服务失联、部分完成、跳过、中断待核实 | 保留输入和上下文，恢复/返回动作明确 |
| 结果 | 空结果、差异、长文本、多页图片、来源与导出 | 无结果不等于执行失败；来源、修订与文件一致 |
| 编辑 | 中文组合输入、粘贴、撤销、保存、切换、刷新、冲突 | 无误提交、丢字、串草稿或覆盖新修订 |
| 键盘 | Tab/Shift+Tab、Enter、Escape、焦点恢复 | 可见焦点、顺序合理、弹层关闭后回到触发处 |
| 视觉辅助 | 对比度、减少动效、加载说明 | 不只靠颜色传递状态，动态反馈不干扰阅读 |
