## 已实现

- DocVortex 0.5.16 在独立 Python 3.12 CPU worker 中解析 PDF、DOCX、PPTX、OFD；PDF 明确使用原生 txt 模式。图片与扫描内容交由现有 OCR 队列处理，混合页继续使用覆盖检查和合并。
- `documents_parse` 异步任务贯通资料库、文档识别、按页/按块读取、搜索、原件查看、Agent 固定来源引用和 JSON/Markdown/原始输出导出。
- MinerU2.5-Pro-2605-1.2B、mineru-vl-utils 2.0.5 使用独立 Python 3.12/CUDA/BF16 worker。固定模型 revision 为 `08aaea840498d49ce16247b6263196cf02814885`，权重和依赖只使用本地封存文件。
- 第五引擎、自动路由、可选后备引擎、页面/指定区域增强识别及前后对照已接入现有工作流。自动模式下 Pro 加载失败只回退一次，默认 PP-OCR；实际引擎和模型身份保存到结果。
- 表格校对独立保存，原始识别及原件哈希保留；XLSX 保留账号前导零和金额原文字面值。未知单元格坐标为空。
- 复用任务、GPU 调度、独立进程和取消恢复。修复了旧共享资产目录不认识 Pro、文档冷恢复复用失效启动记录及失败原因缺失三个实际流程阻断。
- 修复同页同位置、逐格完全一致的原生/OCR 重复表格；保留 OCR 原始快照与确认来源。不同位置、文字不同或定位不足时保留各自结果。

## 已知问题和范围

PDF 覆盖检查可能把原生表格线等内容额外送入区域识别，增加耗时。文字、金额、复杂表格、阅读顺序、页眉单位、脚注和公式仍需人工结合原件抽查。DOCX 为逻辑页，未声称与打印分页一致；本轮 OFD 样例验证文字读取，不代表所有 OFD 结构都已覆盖。

本轮是本机薄候选，依赖已登记的 F 盘共享运行时和模型，不是可迁移安装包。跨页自动拼表、LLM 改写、量化和多机部署继续留待后续。真实业务精度由日常使用反馈改进。
