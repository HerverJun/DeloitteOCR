包内已带运行时，无须自行安装 Node 或 Python。先确认没有别的程序使用目标数据目录。每次启动都会进行完整性检查，本次两个组件的文件校验合计约 17 分钟，进度会显示在启动窗口；不要因短时间没有网页响应而重复启动。

```powershell
$candidate = 'F:\OCR\output\platform-fixed-full-ocr-candidate-r2-20260929'
$env:WORKBENCH_INSTALL_DATA_DIR = 'F:\OCR\output\my-platform-data'
$env:WORKBENCH_PORT = '8782'
& (Join-Path $candidate 'verify.cmd')
if ($LASTEXITCODE) { throw '候选程序校验失败' }
& (Join-Path $candidate 'launch.cmd')
```
