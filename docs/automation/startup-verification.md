# 首次校验与后续启动

同一程序包首次启动会在后台逐件校验 OCR 和分类文件。门户与数据工作台先可用；应用卡片每两秒读取阶段、百分比、已校验/总文件数、用时和当前文件。等待另一应用、校验完成及失败分别显示，不用刷新页面。两个应用的启动状态仍在本轮结束后一次发布。

仅完整校验成功并发布安装状态的应用会保存成功记录。记录位于程序包 `data/startup-verification.json`，绑定程序清单 SHA256、安装绝对路径和校验规则版本，供同一程序包的不同用户数据目录共用；不会写入用户原件或项目数据库。后续启动核对程序清单、应用声明和必要入口后复用记录，不再次扫描全部模型/运行时文件。

升级程序包、搬移安装位置、记录缺失/损坏、必要入口不匹配时重新完整校验。校验失败不保存成功；手动完整校验先作废旧成功记录，失败后不能回用旧成功。

日常快速启动不检测全部非入口文件的内容变化。需要重新排查时，先结束任务并停止本包服务，再使用交付根目录的 `完整校验并启动.cmd`，或设置 `WORKBENCH_FORCE_VERIFY=1` 后运行原启动入口。`verify.cmd` 保留全程序文件独立校验能力。
