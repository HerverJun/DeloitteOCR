# TableFormer 下一步开发：独立复核

2026-09-16。检查当前工作区实现、2026-09-15 的封存实验和产品接入，未修改算法、产品源码、封存数据或历史报告。

**判断：新对应器的提升有可信证据，但不能将四项方向全部视为质量验收完成。发现两项可复现的产品缓存问题；真实 PDF 分类质量验收仍缺独立标注。**

## 需要修复的两项问题

### P2：切回缓存提供方后，预览与 PDF 导出采用不同定位

位置：`src/ocr_workbench/geometry.py:182`、`:363`；`src/ocr_workbench/pdf_export.py:209`。

复现步骤：先完成 TableFormer-local-v3 定位，再完成 Paddle-local-v2；随后重新选择 TableFormer-local-v3 并点击补充定位。第三次请求命中缓存，`enqueue_geometry` 直接返回，没有记录新的有效选择。前端显式传入提供方，所以显示 TableFormer；PDF 导出不传提供方，`geometry_view` 仍选择最近完成的 Paddle 任务。

在隔离 SQLite 测试数据中，同一个单元格的预览框为 `[[0,0],[100,0],[100,40],[0,40]]`，PDF 导出默认取框路径返回 `[[10,10],[100,10],[100,40],[10,40]]`。这不是单纯的模型名称展示差异。复现使用真实缓存/读取逻辑，仅替换模型配置校验，不运行模型。

建议将“用户当前采用的定位方案”与“最近完成的推理任务”分开存储。缓存命中也应更新选择，导出应使用明确的选择快照；增加 A→B→A 缓存切换及切换时仍有待处理任务的回归测试。

### P2：普通缓存命中和读取绕过原始产物完整性检查

位置：`src/ocr_workbench/geometry.py:182`、`:388`。现有校验位于 `complete_geometry` 和候选 CPU 重放路径，普通 mapping 缓存命中提前返回，`geometry_view` 读取时也未验证候选文件或 `upstream.json`。

复现：完成 TableFormer 定位后改变对应 `upstream.json` 的字节；普通请求仍返回 `cached=true`，界面仍把该单元格显示为有效完整格。现有测试仅覆盖强制请求后的候选重放拒绝，因此全量测试通过没有覆盖这个入口。

这会让缓存恢复、文件损坏或实验产物被替换后，界面/PDF 继续使用失去可核验来源的证据，和本轮“读取缓存核验候选及原始文件”的契约不一致。建议普通命中、读取和导出统一使用产物验证状态；验证失败时使自动证据失效并重新排队，保留人工绑定的独立规则。

| 原方向 | 当前证据 | 判断 |

| 重复值和局部锚点改进 | v3 增加双侧邻居约束和到初始锚点的无环来源；关键阈值与预算不变；同候选对照有显著净提升 | 已证明有收益；预算超时和真实合并格仍未解决 |
| 真实输入轨及新的独立测试 | 新增 120 文档、11,278 格双轨测试；公开 PDF 7 份/14 页完成工程运行 | 新裁剪测试完成；原生/中文/整页多表/物理扫描的独立逐格质量验收未完成 |

公开 PDF 的提供框数量不能替代正确数；图像型 PDF 也不能直接当作物理扫描样本。报告已披露这些限制，本次没有把它们当成完整端到端质量证据。

## 独立核对到的进步与缺口

以下是同一批新测试、同一 TableFormer raw 候选和共享 OCR 上的对应器比较，不能与上一轮不同测试集的百分比直接相减。

| 指标 | local-v2 | local-v3 |
|---|---:|---:|
| 控制轨正确覆盖 | 72.57%（8,184/11,278） | **77.50%（8,741/11,278）** |
| 实际采用结构轨正确覆盖 | 65.12%（7,344/11,278） | **69.71%（7,862/11,278）** |
| 控制轨重复值覆盖 | 59.89% | **76.74%** |
| 实际采用结构轨重复值覆盖 | 57.30% | **72.98%** |
| 实际采用结构轨合并格覆盖 | 43.75% | **43.75%** |

控制轨净增 557 个正确格、4.94 个百分点；实际结构轨净增 518 格、4.59 个百分点。原始逐目标计数与报告一致，全部目标留在分母。测试中未观察到 v3 错位，但验证集保留了一个新增空格错位，不能宣称没有风险代价。

控制轨仍有 18 格预算超时，实际轨有 26 格；分别损失 8 / 16 个 v2 已正确定位的格。对应器不能视为逐格单调改善。限制邻居搜索成本应继续优先于扩展规则或提高预算。实际结构轨还有 1,734 个参考目标无法关联采用输出，合并格中占 153/352；进一步改文字对应无法单独解决上游跨度/结构错误。

当前结果仍低于预定 90% 覆盖门槛。保留 Paddle + local-v2 默认及 TableFormer/local-v3 实验选项是合理的。
