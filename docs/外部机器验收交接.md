# 外部机器验证工具说明

当前开发机不是另一台干净 Windows，也不是目标 RTX A4000，内网真实数据也没有测量结果。2026-09-12 已删除人工验收与回传要求；以下保留后续外部环境验证可用的自动化工具说明，工具输出仅证明实际覆盖的环境与负载。

## 适用环境

- Windows 及兼容 NVIDIA 驱动与 Edge/Chrome。应用包自带 Python、模型及静态前端，不需要系统安装 Python、Node.js 或 CUDA Toolkit。
- A4000 专项工具对应 Xeon W5-2455X、64 GB RAM、RTX A4000 16 GB；工具会检查实际机器配置。
- 安装命令扫描只能提供环境线索，不能单独证明机器没有开发环境；本机或沙箱运行也不能证明另一台机器兼容。

## 运行方法

自动化复测可将完整候选 ZIP 解压到有中文和空格的路径，例如 `D:\OCR 验收\便携 工作台`。系统禁网测试从目标电脑的管理员 PowerShell 运行：

```powershell
$ocrBundle = 'D:\OCR 验收\便携 工作台\OfflineOCR'
$ocrEvidence = 'D:\OCR 验收证据\第一次系统禁网'
& "$ocrBundle\tools\offline_guard.exe" $ocrBundle $ocrEvidence --application
```

目录应按实际解压位置调整。证据目录必须不存在或为空。该命令以 WFP 动态规则阻断 OCR 可执行文件的外网连接，保留本机回环，实际运行四引擎；退出自动移除规则。回执必须显示 Python 运行时及原生 Winsock 外网探针被系统拒绝，并绑定当前机器与包清单。

完整应用回归可从普通 PowerShell 运行：

```powershell
& "$ocrBundle\runtimes\service\python.exe" -B -X utf8 -I "$ocrBundle\tools\audit_application.py" --bundle $ocrBundle --output 'D:\OCR 验收证据\应用回归'
```

A4000 专项复测命令：

```powershell
& "$ocrBundle\runtimes\service\python.exe" -B -X utf8 -I "$ocrBundle\tools\target_machine_acceptance.py" --bundle $ocrBundle --output 'D:\OCR 验收证据\A4000' --role a4000 --os-isolation-evidence $ocrEvidence
```

目标机流程包括完整应用、20 次加载卸载与 500 张工程队列，保存原始时间和显存采样。约 2 GB 余量检查只证明这组负载，没有内网真实大图的性能结论。

更换盘符和中文/空格路径的自动化复测使用同一个 ZIP 与新的证据目录；运行前退出原实例，回执记录路径、机器指纹和包清单哈希。开发机目录搬迁只能证明本机路径兼容。

## 证据范围

候选 ZIP 的 SHA-256、`target-machine.json`、系统禁网回执与工程输出用于绑定包版本、机器与测试范围。当前已有本机回执，干净 Windows、实际 A4000 与内网真实数据仍无通过证据；当前融合开发状态见 [融合实施记录](fusion-implementation-status.md)。
