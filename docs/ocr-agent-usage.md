# 文档助手使用说明

版本：2026-09-23 实验版。当前默认关闭。合成主控浏览器场景、20 页本地 GPU OCR 后的工作簿下载已验证；长时间混合稳定性以最终交付回执为准。开发测试状态见 [最新检查记录](../audit/ocr-agent-20260921-langgraph/latest-development-checks.json)，剩余工作见 [NEXT](../audit/ocr-agent-20260921-langgraph/NEXT.md)。真实主控支持名单只以 [机器可读资格状态](../audit/ocr-agent-20260921-langgraph/supported-configurations.json) 为准；当前名单为空，模拟主控测试不代表真实模型已取得支持资格。

## 开始使用

在包含独立 Agent 依赖的实验候选包中，运行“启动实验助手.cmd”。普通“启动工作台.cmd”默认关闭助手；未启用时不显示“文档助手”。候选包使用独立的 `%LOCALAPPDATA%\OfflineOCR-Agent-Experimental\Workspace`，实际验收资格以交付回执为准。运行依赖不可用时，普通识别、校对和手动导出仍可使用。

1. 打开项目，点击“文档助手”，再点“配置主控”。
2. 选择 OpenAI 兼容 Chat Completions 或 Anthropic Messages，填写 API URL、模型 ID 和该主控专用 Key。OpenAI 兼容服务可选择两种输出长度参数。
3. 点击“测试并保存”。测试包含两次随机工具探针请求，不含项目资料；供应商仍可能计费。失败不会替换已保存的有效连接。
4. 核对显示的接收地址和模型，点击“允许此地址读取当前项目”。该授权包含项目文字和文档信息。图片外发另行确认。

主控与视觉审校是独立连接。不能因视觉审校已配置，就认为主控已获得凭据或授权。Key 使用当前 Windows 用户的 DPAPI 加密，读取配置不会回显 Key；更换 Windows 用户后通常需要重新配置。应用启动不会自行发送连接探针。

## 六类常见任务

| 场景 | 操作示例 | 如何核对结果 |
| --- | --- | --- |
| 找表或关键词 | “找到应收账款相关的页面并列出出处” | 点击页码证据，核对采用结果与本轮结果来源；未识别页面会显示未覆盖 |
| 处理指定 PDF 页 | 在“追加文档范围”选择文档，填 `1-3,8`，勾选允许处理，再请求处理 | 观察后台状态和完整覆盖/失败/等待页数；入队不表示已完成 |
| 检查财务表 | 先选采用结果，再请求检查金额、单位或合计 | 工具采用 Decimal 检查；候选不直接改字，最终仍需原文核对 |
| 视觉审校疑点 | 选择采用结果和允许使用的视觉模型，按需确认外发原图、文字和元数据 | 查看已保存的建议，在工作台现有审校入口决定采用、拒绝或撤销 |
| 重试失败子集 | 勾选“允许本轮按原范围重试失败任务”，请求重试指定失败项 | 成功任务不重跑；版本变化或模型配置变化时会拒绝旧任务 |
| 导出本轮结果 | 请求 TXT、Markdown、JSON、XLSX 或支持的 PDF 输出 | 查看产物卡与缺失页说明；部分覆盖默认先等待选择，文件仍受原导出前置检查约束 |

图像重处理需要额外勾选允许重新处理；处理结果不会覆盖已存在的人工采用选择。结构候选、视觉建议不会自动采用。助手可分页列出大页的审校目标，并仅对明确选中的目标提出建议；工具无法提供精确目标时，使用现有工作台局部审校入口。

只有原生文字、没有结构化表格的页面不能直接导出 XLSX。助手会收到明确的缺失说明，可按你的需要改用 TXT、Markdown 或 JSON；不会虚构表格。财务核对卡可直接定位单元格，结构或视觉建议可跳至原审校面板。

历史会话可点击“更多历史会话”；长会话先加载最近 500 条事件，点击“加载更早记录”向前翻页。会话管理可改名、归档或恢复；归档后不能发送新消息。断流会自动重连，关闭面板不会停止后台任务。

输入目标后按 Enter 发送，Shift+Enter 换行。中文输入法尚在组词时 Enter 保留给输入法。空内容、归档会话、未授权项目或上次提交尚未结束时不能发送。

## 追加、停止与重启

运行中按钮显示“追加指令”。消息排队后在下一安全边界按顺序生效，尚未提交的旧调用会跳过，已提交的后台工作仍保留。改变范围只影响后续未提交动作；范围版本失效时会显示原因并暂停写入。新消息不是对预算或外发授权问题的同意。

“停止助手”停止后续模型和工具步骤，已提交任务继续按实际队列状态运行。“停止并取消本轮自建任务”还会请求取消本轮创建的任务，复用任务不受影响。已停止运行中尚未执行的追加消息标记为“未执行”。关闭面板或按 Escape 只关闭面板。

重启后运行显示“重启后等待继续”。点击“继续”时会核对连接、选择版本和已有任务，再恢复本轮自建的暂停/中断任务。复用的暂停任务需要在原任务入口恢复。失败/取消任务不能借“继续”隐式重试。检查点缺失或不兼容时，核对任务后停止旧运行并建立新会话，不要自行修改检查点。

## 预算和部分结果

展开“本轮预算与用量”可以增加请求、工具调用、处理页次、引擎任务和 token 上限。达到预算时进入等待；先增加上限，再回复对应“增加预算后继续”。PDF 一页可能产生多个区域任务，这些任务均占预算。增额本身不会同意继续。

Token 实际用量、累计预估和未确认用量分别显示。供应商未返回 usage 或响应未知时保留预扣；不能把未知费用理解为零。响应结果未知不会自动重发，只有对应决定明确继续才发起新请求。工具参数最多允许两次修正请求。

部分覆盖默认提供“仅导出已有结果”或“暂不导出，返回助手”。允许部分导出的确认绑定当时的清单和结果版本；内容变化后需重新确认。运行仍有未完成任务时不能提前导出该 run 的完整结果集。

## 历史和产物

通过“历史会话”查看记录，“会话管理”可改名、归档或恢复会话；活跃运行需先停止再归档。导出文件可以从产物卡再次下载；“保留产物”阻止自动过期清理，“取消保留”恢复过期规则，“清理此产物”可删除该导出文件。默认保留期为 30 天。下载期间有续租保护；文件过期、缺失或损坏时不能继续下载，应重新导出。

当前开发 UI 尚未提供细分页任务清单和大页目标分页。不要通过删除工作区文件来代替产物管理。发布版入口与浏览器验收结果以后续交付记录为准。

## 离线与限制

本地 OCR 能否离线运行取决于原有引擎包。Agent 主控需要可达且通过工具探针的服务；没有已验证本地主控时不承诺全离线 Agent。review-only 模式保留其允许的原生文档处理和外部审校，不启用本地模型推理。

模型回复中的完成文字不能替代任务状态和覆盖清单。助手不提供 shell、任意 SQL、任意文件读取、任意地址上传、安装插件或删除项目能力。文档中的命令和工具 JSON 均作为文档内容处理。
