界面首选本地打包的 Noto Sans SC 可变字体（Workbench Sans），回退 Segoe UI / 微软雅黑；字体不通过网络加载。字体来自 Google Fonts 官方 notosanssc 目录，采用 SIL Open Font License 1.1，许可随包提供。正文、表格为 14px；辅助信息不小于 12px。数字启用 tabular-nums。长编号保持文本且不自动换行，宽表格仅在编辑区域内部滚动。

主控件高度 32–36px，圆角 4–6px；原图与校对面板采用 10px 圆角，浮层采用 12px 圆角。间距使用 4/8/12/16/24px。交互过渡 150ms，尊重 prefers-reduced-motion。Fluent UI 与原生控件共享中性色、品牌色及焦点设计。

## 空间与交互

- 顶栏 44px，资料栏默认 248px。原图与结果默认 48:52，分隔线支持拖动、方向键、Home/End、Enter 和双击复位。
- 资料栏开关、分栏比例、模式、引擎记忆在浏览器本地。同源重开保留；启动器随机端口变化时允许恢复默认。存储不可用时仍可正常操作。
- 宽度低于 1200px 默认收起资料栏；从大窗口缩小时自动收起，用户仍可展开。
- 宽度低于 1000px 或高度低于 680px，切换为“原图 / 校对”单区视图。隐藏区域保持挂载，不丢失当前编辑或图像操作状态。
- 资料过滤不自动清除隐藏的已选图片。全选仅作用于当前可见图片；同时显示筛选外已选数量，并提供清空操作。
- 首次进入默认表格模式；首次加载结果有表格则打开表格，否则打开文字。主动选择的页签按结果在当前页面会话内记忆，后台刷新与保存不抢焦点。
- 批量范围显示已选张数；无选择时只处理当前图片。队列停靠在工作区下方，正常高度下压缩编辑区域；极低窗口允许结果区内部滚动，导出栏保持可达。
- 表格标题及详细说明放入可展开设置。常用加减行列、合并拆分保持直接可见。原始输出独立保留，不清洗、不替换。
- 项目管理、图像低频修正使用可折叠菜单；设置及导出保留 Fluent UI 对话框与原有确认语义。

## 验证与兼容

新布局不修改 HTTP API、项目数据或 OCR 推理设置。应用更名不改变 `OfflineOCRLauncher.exe` 文件名及现有用户目录，旧项目直接使用。

前端验证：`npm run build`、`npm test`。GUI 回归使用 `frontend/scripts/ui-audit.mjs`、`ui-features.mjs` 和 `ui-redesign.mjs`，通过环境变量指定独立服务状态文件与证据目录。

截图使用外部 Edge/Chromium，参数 `--disable-gpu --disable-gpu-compositing`，完成后关闭测试浏览器。新版证据必须关联新版清单，不复用旧版通过状态。

## 第二轮视觉精修与资源来源

新增项目面包屑与工作标题，原图及校对成为独立面板；页签与编辑历史合并一行，表格工具加入 A1 地址与 A/B/C 列标识。中性灰黑承担正文，绿色集中用于选择、焦点和关键操作。精修变量和组件覆盖集中在 professional.css，保留原功能样式以避免改变画布坐标与编辑逻辑。

- 精修正文 #202823，辅助文字 #66706A，画布 #EEF1EE，工作区 #F4F6F4，边界 #E2E7DF；字标及主按钮保留 #86BC25。
- 空项目插画 document-illustration.svg 通过用户指定的 sub2api Responses 接口，由 gpt-6-astra 主模型调用 image_generation 工具生成参考图并产出矢量资源。已完成 XML 元素、外链与事件扫描，无脚本、嵌入位图或运行时外部链接。提示词、回执及参考 PNG 归档在独立交付证据 asset-generation 目录。

- Noto Sans SC 来源：https://github.com/google/fonts/tree/main/ofl/notosanssc ，字体及 OFL 均随应用本地提供。
