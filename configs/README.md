# 配置使用说明

`document-project.json` 是文档截图四分类试点配置，`general-image-project.json` 是可替换标签的通用整图分类示例。二者均为 planned，供后续实现读取和开展 P0 验证，当前没有与之配套的训练程序。

配置由 `schemas/project.schema.json` 约束。业务标签必须互斥，label_id 唯一；split 比例之和必须为 1；复核配额之和等于每轮预算。DINOv2 的输入边长须满足 patch14 约束，并在 timm 创建模型时显式配置。

当前模型名称已在机器现有 timm 1.0.22 注册表查询确认，未下载权重；最终使用的 timm 版本需重新加载与导出验证。`weights_sha256: null` 明确表示尚未获取权重，不能直接生成正式模型包。

acceptance 中的 null 表示业务目标及阈值尚未确定，不允许解释为零阈值或默认全部接受。模型元数据 Schema 要求正式阈值、来源版本与 validated 状态。JSON Schema 只校验字段形状；类别连续索引、阈值键集合、输入输出张量与文件哈希还必须在 P1 的模型加载器执行语义校验。

示例标签、路径和样本清单都不是已导入的业务资产。80,000,000 最大解码像素是初始保护值，遇到真实超长截图应根据内存与业务要求调整，并记录为新预处理版本。
