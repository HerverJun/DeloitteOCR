# 台账核对口径

左右表角色由用户目标和资料名称确定。列需经过原生探查；样本相同不等于整个列类型一致。

业务编号按原文文本保留，尤其是 `000001`、长编号、包含字母的单号。金额使用 decimal 和字符串阈值，例如 `"0.01"`；不要用 float 或任意四舍五入抹掉差异。币种和单位不明时不能跨币种直接比较。

重复键先用 duplicates 检查并报告；多对多键不能自行选一行。空键按明确 null_policy 处理。期间和负数/红字票据规则由用户背景确定。列转型错误、缺失金额和失败输入进入限制说明。

行来源是证据链的一部分。保持 source_rows 和结果引用，通过现有证据工具固定。导出 CSV 的安全转义用于展示；再次计算应使用 Parquet 原值文件或受控结果桥。
